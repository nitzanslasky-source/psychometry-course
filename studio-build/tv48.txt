# Topic 48 Rules and arrangements

######## SECTION vr48-learn — Learn and try (learn)
=== VIDEO vr-rules-method: kind=lesson title='Rules and arrangements: build a small working model'
[1] Use the shape the problem gives you
  BOARD: ['Order → numbered slots', 'Groups → boxes', 'Two qualities → a small table']
  SCRIPT: An arrangement question becomes easier when the page has the same shape as the task. If five talks are in order, draw five slots. If books are divided between shelves, draw two boxes. If each item has a color and a material, make a small table rather than trying to hold both descriptions in one sentence. This is active reading made visible. Copy only the rules that restrict the arrangement. The names are labels, not facts to memorize. Once the model is on the page, you can test possibilities without rereading the whole paragraph every time.
[2] Translate each rule once
  BOARD: ['Before ≠ immediately before', 'Together ≠ in a particular order', 'At least one ≠ exactly one']
  SCRIPT: Before means somewhere earlier. Immediately before means the two items form a block with no gap. Together may allow either internal order unless one is specified. At least one allows two; exactly one does not. These distinctions are often the whole question. Use a short symbol only after you understand the wording. You might write A before B as a loose arrow, and draw AB inside one box when the two must be adjacent in that order. If a rule says either one course or the other but not both, mark the exclusion explicitly. Do not silently treat every ordinary ‘or’ as exclusive.
[3] Place the tightest condition first
  BOARD: ['Fixed position', 'Adjacent block', 'Restricted pair', 'Then the flexible items']
  SCRIPT: Start with the rule that leaves the fewest choices. A fixed last position is easy to place. A three-item consecutive block in five slots has only three possible starting positions. A rule saying one item is somewhere before another is usually looser. This order of work is not a formal requirement, but it reduces the number of branches you must consider. If an arrangement is not fully determined, that is not a failure. The question may ask only what could happen or what must be shared by all arrangements. Stop filling unnecessary slots when the demanded conclusion is already settled.
[4] Must, could and cannot need different evidence
  BOARD: ['Could → one complete valid arrangement', 'Not must → one valid counterexample', 'Must → all cases, or a forced chain']
  SCRIPT: For a could question, build one complete example that satisfies every rule. For a must question, a single example is not enough; you need a forced deduction or a complete set of cases. To reject a proposed must statement, one valid counterexample is enough. For a cannot question, show the rule that every attempted version would break. Circle the demand before you start. It is frustrating to build a beautiful valid arrangement and then choose an answer that merely could happen when the question asks what has to happen.
[5] Keep separate rankings separate
  BOARD: ['Age order', 'Height order', 'Do not merge them unless a rule connects them.']
  SCRIPT: A question may compare the same people by age and height. Being older does not automatically mean being taller. Keep two rows, one for each ranking. If a rule permits an action when a person is older or taller, check either route independently. If it requires both, check both. The same care applies to floors and room numbers, colors and materials, or speaker order and team membership. A neat diagram helps only if it preserves the distinctions in the text. Combining different dimensions into one convenient-looking line can create a false conclusion.
[6] Truth-count puzzles: test a complete case
  BOARD: ['Exactly two true statements', 'Assume a candidate → evaluate all statements', 'Count, then keep or reject the case']
  SCRIPT: When exactly two statements must be true, do not decide the truth of each in isolation. Pick a candidate situation and evaluate every statement in that same situation. Count the true ones. If the count is wrong, reject that candidate. This is often easier than trying to manipulate several negatives at once. A small table with candidate rows and statement columns makes the work visible. Keep the rule about the number of truths separate from the statements being evaluated. It is a condition on the whole row, not permission to declare whichever two statements you prefer true.
[7] Use the answers as proposed models
  BOARD: ['Check the most restrictive rule first.', 'Name the first rule an option breaks.', 'Confirm the surviving option against every rule.']
  SCRIPT: If the choices are complete schedules, the answers have already done some of the arrangement work for you. Test the fixed positions and adjacent blocks first, since they are quick to check. Reject an option as soon as it breaks a rule. But once only one survives, check it against every rule rather than trusting elimination alone. In independent practice, the written solutions include valid arrangements or counterexamples where appropriate. These are not extra facts added to the question. They are concrete models showing what the given rules permit.
--- Q vr48-g001: A student must take exactly one of Ceramics and Film. Anyone taking Film must also take Music. Which selection satisfies both rules?
  CHOICES: ['Film and Music, but not Ceramics', 'Ceramics and Film, but not Music', 'Music only', 'Film only'] correct=1
=== VIDEO solve-vr48-g001: kind=solution title='Exactly one of two courses'
[1] Your question
  BOARD: []
  SCRIPT: A student must take exactly one of Ceramics and Film. Anyone taking Film must also take Music. Which selection satisfies both rules?
[2] Put the message in plain English
  BOARD: ['Film and Music, but not Ceramics']
  SCRIPT: Exactly one permits Film without Ceramics, and Film then requires Music. The other selections either include both alternatives, neither, or Film without its requirement. Draw the smallest model that keeps all the rules visible. Put fixed positions or a tightly constrained block in first. Then check every remaining rule in the same arrangement; an option cannot borrow one fact from one possible case and another fact from a different case.
[3] Keep each answer tied to the text
  BOARD: ['Exclusive choice']
  SCRIPT: “Ceramics and Film, but not Music” fails because this includes both courses and also misses Film’s required companion. “Music only” fails because this includes neither of the two required alternatives. “Film only” fails because film requires Music. We have a reason for rejecting each alternative. That matters more than whether an answer repeats a familiar word from the passage. A strong distractor often borrows the vocabulary while changing the owner, direction or strength of the claim. Return to the exact part of the text that decides between the closest two options.
[4] Choose the matching answer
  BOARD: ['Choice 1', 'Film and Music, but not Ceramics']
  SCRIPT: The answer is choice 1: Film and Music, but not Ceramics. Exactly one permits Film without Ceramics, and Film then requires Music. The other selections either include both alternatives, neither, or Film without its requirement.
