## New methods taught (lesson slides)
**Video "Averages" (wp-080): 4 new slides, recap rebuilt, sidebar updated**
- *Evenly spaced* (after "The middle"): 3, 7, 11, 15, 19. The average is the middle number = (first + last) ÷ 2. Also consecutive numbers, and an even count of values.
- *The balance* (after "Towers of blocks"): the amount above the average equals the amount below it. Example 86, 93, 95, ? with average 90 gives −4 + 3 + 5 = +4, so ? = 86.
- *A base number* (after "The formula"): 97, 102, 104, 99 with base 100 gives +2 ÷ 4, so the average is 100.5.
- *Every value changes* (after "One value changes"): +k to every value → average +k; ×k → average ×k; ages in 5 years; both at once (8, 10, 12 → ×3 + 1).
- Recap: 6 lines (new: evenly spaced, balance, every value +k/×k).

**Video "Sum from the Average" (wp-081): 2 new slides, recap rebuilt**
- *Largest possible value*: make the others as small as possible. Trap: *different* integers (1, 2, 3, 4, not 1, 1, 1, 1).
- *How many were there?*: average 20, a new value 30 joins, new average 22 → (30 − 22) ÷ (22 − 20) = 4 values before. Also shows the equation and the "before/after" trap.

**Video "Weighted Averages" (wp-086)**
