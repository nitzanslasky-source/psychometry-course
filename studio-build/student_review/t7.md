### Q 1 (q-191): Given: \({x}^{7} = {x}^{6} \cdot  y\). \(y = ?\)
  (1) x
  (2) \({x}^{6}\)

  correct: 3
  solution: If x ≠ 0 , divide by x⁶ to get y = x . But if x = 0 , the equation is 0 = 0 and holds for every y. Different cases, different conclusions — y is not determined.

### Q 4 (q-194): Given: \(\frac{a - 5\,b}{4} = 1 - b\). Which of the following statements is necessarily true?
  (1) \(a < b\)
  (2) \(b < a\)
  (3) \(a = b\)
  (4) \(a = 4\,b\)
  correct: 1
  solution: Multiply by 4: a − 5b = 4 − 4b . Add 5b : a = 4 + b . So a always exceeds b by exactly 4, and b < a holds unconditionally.

### Q 7 (q-197): Given: \(2\,a + 3\,b + 3\,c = 23\), \(a + b = 3\), \(2\,b + c = 4\), \(a + c = 10\). \(c = ?\)
  (1) \(6\)
  (2) \(8\)
  (3) \(5\)
  (4) \(4\)
  correct: 0
  solution: Decompose the big left side using the three small givens: (a + b) + (2b + c) + (a + c) = 2a + 3b + 2c , which is the target minus one c. So 2a + 3b + 3c = 3 + 4 + 10 + c = 17 + c . Since that equals 23, c = 6 . (Direct solving agrees: a = 3 − b , c = 10 − a = 7 + b ; then 2b + 7 + b = 4 → 3b = −3 → b = −1 , giving c = 6 .)

### Q 10 (q-186): Given: a, b, c, \(d \ne  0\) and \(\frac{a}{b} = \frac{c}{d}\). Which of the following statements is not necessarily true?
  (1) \(a = \frac{bc}{d}\)
  (2) \(d = \frac{bc}{a}\)
  (3) \(\frac{d}{b} = \frac{c}{a}\)
  (4) \(\frac{c}{b} = \frac{d}{a}\)
  correct: 3
  solution: Cross-multiplying the given yields ad = bc . Claims (1), (2), (3) each cross-multiply back to ad = bc , so they always hold. Claim (4) cross-multiplies to ac = bd — a different relationship not implied by ad = bc . Counterexample: a = 1 , b = 2 , c = 3 , d = 6 satisfies a:b = c:d (1:2 = 1:2) , but c:b = 3:2 while d:a = 6 — unequal.

### Q 11 (q-187): The sum of the squares of two integers equals the square of their sum. Which of the following is necessarily true?
  (1) The two numbers are equal to each other
  (2) The sum of the numbers equals zero
  (3) The two numbers are reciprocals of each other
  (4) One of the numbers equals zero
  correct: 3
  solution: Let the numbers be a and b: a² + b² = (a + b)² = a² + 2ab + b² . Subtracting a² + b² from both sides: 0 = 2ab , so ab = 0 — which means a = 0 or b = 0 .
