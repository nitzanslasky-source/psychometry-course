### Q 1 (q-358): Given: \(a \cdot  b < 0\) and \(a < \left|a\right|\). Which of the following statements is correct?
  (1) \(\left|b\right| < \left|a\right|\)
  (2) \(\left|b\right| = b\)
  (3) \(b < 0\)
  (4) \(\left|\frac{a}{b}\right| < 1\)
  correct: 1
  solution: The condition a < |a| means a differs from its own absolute value, which happens only when a is negative. Since a·b < 0 , the product is negative, so a and b have opposite signs — a negative forces b positive. A positive number equals its absolute value: |b| = b . Nothing in the givens compares the magnitudes of a and b, so (1) and (4) aren't forced.

### Q 5 (q-362): Given: \(x < 0\). What is \(5 + \frac{2\,x}{\left|x\right|}\)?
  (1) \(7\)
  (2) \(3\)
  (3) \(-x\)
  (4) \(5 - x\)

  solution: Since x < 0 , |x| = −x . So 2x:|x| = 2x:(−x) = −2 . Therefore 5 + 2x:|x| = 5 − 2 = 3 , regardless of the specific negative value of x.

### Q 6 (q-363): Given: \(\left|b\right| = a\), \(b \ne  a\), and \(3\,c = a\). Which of the following statements necessarily follows?
  (1) \(a < c < b\)
  (2) \(b < a < c\)
  (3) \(c < b < a\)
  (4) \(b < c < a\)
  correct: 3
  solution: |b| = a means b = a or b = −a ; since b ≠ a , we get b = −a . Also a = |b| ≥ 0 , and a ≠ 0 (if a = 0 then b = 0 = a , contradicting b ≠ a ), so a > 0 and b = −a < 0 . Finally c = a:3 , which is strictly between 0 and a. Ordering: b (negative) < c (between 0 and a) < a.

### Q 7 (q-364): Given: \(p < q < 0 < r < s\). Which of the following statements necessarily follows?
  (1) \(\left|p\right| < \left|s\right|\)
  (2) \(\left|q\right| < \left|s\right|\)
  (3) \(\left|r\right| < \left|p\right|\)
  (4) \(\left|q\right| < \left|p\right|\)
  correct: 3
  solution: p and q are both negative with p further left: p < q < 0 . For negatives, farther left means larger absolute value: |p| = −p > −q = |q| . So |q| < |p| always. The other comparisons cross the zero line and depend on unspecified magnitudes — e.g., p = −100 , s = 1 kills (1) and (2), while r = 5 , p = −1 kills (3).

### Q 8 (q-365): Given: \(d < c < b\) and \(\left|b\right| < \left|c\right|\). Which of the following statements is not necessarily true?
  (1) \(b \ne  \left|b\right|\)
  (2) \(\left|c\right| < \left|d\right|\)
  (3) \(\left|b\right| < \left|d\right|\)
  (4) \(d \ne  \left|d\right|\)
  correct: 0
  solution: From |b| < |c| with c < b , the number c must be negative (if c were ≥ 0 then b > c ≥ 0 would give |b| = b > c = |c| , a contradiction). Then d < c < 0 , so d is negative too, and |d| > |c| > |b| — making (2), (3), (4) always true. But b's sign is NOT forced: b = 1 , c = −2 , d = −3 satisfies everything with b = |b| , while b = −1 , c = −2 , d = −3 gives b ≠ |b| . So (1) is only sometimes true.

### Q 9 (q-366): a and b are integers. Given: \(2 < \left|a + b\right|\). Which of the following statements is possible but not necessarily true?

### Q None (q-384): In which of the following situations is the equation \(\left|c\right| + \left|d\right| = \left|c + d\right|\) not necessarily true?

  solution: The identity |c| + |d| = |c + d| holds exactly when c and d do not have opposite signs (c·d ≥ 0) .
