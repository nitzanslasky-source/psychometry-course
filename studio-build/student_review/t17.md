### Q 1 (q-493): Given: \(1 < a < b < c < d\). Which of the following statements is not correct?
  (1) \(a \cdot  b < c \cdot  d\)
  (2) \(a \cdot  c < b \cdot  d\)
  (3) \(b < c \cdot  a\)
  (4) \(a \cdot  d < c\)
  correct: 3
  solution: All four numbers exceed 1. (1) a < c and b < d , so the product of the two smaller numbers is less than the product of the two larger — true. (2) a < b and c < d — true for the same reason. (3) since a > 1 , c·a > c , and c > b , so c·a > b — true. (4) since a > 1 , a·d > d , and d > c , so a·d > c always — meaning a·d < c is impossible, making it the incorrect claim.

### Q 2 (q-494): Given: \(-1 < t < 0\). Which of the following expressions is the smallest?
  (1) \({t}^{6}\)
  (2) \({t}^{5}\)
  (3) \(\sqrt[3]{t}\)
  (4) \({t}^{-1}\)
  correct: 3
  solution: Test t = −0.5 : t⁶ = 0.015625 (a small positive); t⁵ = −0.03125 (a tiny negative, close to zero); ³√t ≈ −0.794 (odd root of a negative fraction moves away from zero, but stays between −1 and 0); t⁻¹ = 1:(−0.5) = −2 (the reciprocal of a fraction between −1 and 0 amplifies the magnitude past −1 ). Ordering: −2 < −0.794 < −0.031 < 0.016 , so t⁻¹ is the smallest.

### Q 3 (q-495): Given: \(1 < a < b < c\). Which of the following expressions is the smallest?
  (1) \(b \cdot  {c}^{2}\)
  (2) \(a \cdot  {b}^{2}\)
  (3) \(b \cdot  {a}^{2}\)
  (4) \({b}^{3}\)
  correct: 2
  solution: Test a=2 , b=4 , c=5 : b·c² = 100 ; a·b² = 32 ; b·a² = 16 ; b³ = 64 . The smallest is b·a² . Structurally: b·a² pairs the smallest possible squared factor ( a² , smaller than b² or c² ) with a linear factor b that is no larger than the linear factors in the competing expressions — so it loses every comparison and is the minimum.

### Q 4 (q-496): Given: \(0 < p < q < 1 < r < s\). Which of the following statements is not necessarily true?
  (1) \(q \cdot  s < s\)
  (2) \(\left(r - q\right) < \left(s - p\right)\)
  (3) \(r < \left(\frac{r}{p}\right)\)
  (4) \(\left(r + q\right) < \left(s + p\right)\)
  correct: 3
  solution: (1) is always true: multiplying s by the fraction q < 1 shrinks it. (2) is always true: r < s and −q < −p (since p < q ), so r−q < s−p . (3) is always true: dividing by a positive fraction p < 1 enlarges r. (4) can fail: take p = 0.8 , q = 0.95 , r = 1.05 , s = 1.1 — then r+q = 2.00 while s+p = 1.90 , so (r+q) > (s+p) . Since it holds for spread-out values but fails here, it is not necessarily correct.

### Q 5 (q-497): Given: \(-1 < a < 0 < b < c < 1\). Which of the following expressions is the largest?
  (1) \(a \cdot  b \cdot  c\)
  (2) \(a \cdot  c\)
  (3) \(a \cdot  b\)
  (4) a
  correct: 0
  solution: All four expressions are negative (each contains the negative a; b, c are positive). Among negatives, the largest is the one closest to zero. Multiplying by fractions of magnitude less than 1 shrinks magnitude, so the more fraction-factors, the closer to zero. Test a = −0.4 , b = 0.2 , c = 0.5 : a·b·c = −0.04 ; a·c = −0.2 ; a·b = −0.08 ; a = −0.4 . The closest to zero, −0.04 , is a·b·c .

### Q None (q-503): Which of the following numbers is the largest?
  (1) \({\left(\frac{1}{3}\right)}^{2}\)
  (2) \({\left(\frac{1}{3}\right)}^{\frac{1}{2}}\)
  (3) \({\left(\frac{1}{3}\right)}^{\frac{-1}{2}}\)
  (4) \({\left(\frac{1}{3}\right)}^{-2}\)
