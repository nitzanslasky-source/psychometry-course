# Topic 3: Comparing Fractions

## Most important points

1. **The "always works" claim for cross-multiplication is false.** Slide 5, slide 11 and the memory card say it "always works" and "eats everything, even with letters". This is true only when both denominators are positive. Example: compare 1/(−2) and 1/3. Products above the numerators: 3 and −2, so the method says the first is bigger. Wrong: −0.5 < 0.33. With letters (slide 9, Q9, q-088) the sign is often unknown, so this is a real exam trap. Fix: add one line to slide 5 and to the card: "Cross-multiply only when both bottoms are positive."
2. **Squaring also needs positive numbers.** Slide 8 says "The bigger one stays bigger after squaring." Only true when both are positive (−3 < 2, but 9 > 4). Add "both positive" on the board. The practice solution t3-1-4 says it; the video does not.
3. **Solution text looks broken in this export** (check what the student really sees):
   - Q1 solution: "2×7=1417" — the "<15 … 2×9=18>" part is missing.
   - Q7 solution: "x:y  1" — a sign is missing. Q7 video slide 3: `Write "0  1"` — should be something like "0 < x/y < 1 → y/x > 1".
   - Solutions write fractions as "5:12", "7:15". In an English course this reads like a ratio. Use a slash (5/12) in solution text.
4. **q-087 solution is confusing.** It says m = 0.004, n = 0.002 gives m − n = 0.002, "neither greater than 1 nor pinned inside (0, 1)". But 0.002 *is* inside (0, 1), so this example kills only choice 1. To kill choice 2, use m = 4, n = 2 (m − n = 2). Rewrite with two clear examples.

## 1. Coverage — missing or too thin

- **Adding the same number to top and bottom.** A classic NITE rule: for a positive fraction below 1, adding the same positive number to top and bottom moves it up toward 1 (above 1: down toward 1). Not taught at all.
- **Mediant / "pieces" idea.** Q10 (3/16, 4/21, 5/26) and q-090 are built this way: each step adds 1/5 (or 1/…) to the fraction. The strong student should see that the list moves toward 1/5. Nice fourth method for Q10.
- **x, x², √x, 1/x for 0 < x < 1 and for x > 1.** Very common "which is largest" question. It appears only in practice (t3-1-5), never taught. Add a small table: for 0 < x < 1, x² < x < √x < 1 < 1/x; for x > 1 the order flips.
- **Negative fractions.** Ordering negative fractions (−2/3 vs −3/4) is never shown. "Flip reverses order" (slide 10) is true only when both have the same sign — say so.
- **Fractions above 1.** "Distance from 1" (slide 7) is shown only below 1. q-089 (7/6, 9/7, 19/15, 19/16) is solved by "subtract 1": 1/6, 2/7, 4/15, 3/16. Show this on slide 7 in one line.
- **Common decimal values** (1/8 = 0.125, 1/3, 1/6, 1/7 ≈ 0.14, 1/9) — slide 6 says "you need to know your decimals" but no list. Put a mini-table in the memory card.
- Minor: "necessarily true" vs "could be true" question wording is explained only in Q7. Name it earlier (slide 9).

## 2. Teaching quality per level

**Weak student**
- Slide 5: "It's secretly a common denominator" is said once and fast. Show it on the board: 5/8 = 55/88, 7/11 = 56/88. Then "above its numerator" makes sense, instead of being a rule to memorise.
- Slide 8 (roots) comes before roots are taught. The weak student will stop here. Move it to the end, or mark it "optional for now".
- Slide 9 (plug in) has no answer choices on the board, but the teacher says "knock out three choices". Too abstract. Put four choices on the board, or move this slide next to Q6/Q7.
- Q3 needs "multiplication and division: left to right" — it is said, good. Tell the student that ":" means "divide" on the exam.

**Medium student**
- Good: the tournament method (Q8, Q9) and two methods per question. The memory card "when to use" column is very useful.
- Gap: no rule for choosing plug-in values. Add: avoid 0 and 1 when they make choices equal; after one success, try a negative or a fraction (Q7 shows this well — say it as a general rule).

**Strong student**
- Slides 2–4 are slow for this student, but short. Acceptable.
- Missing the fast tools: adding to top and bottom, x vs x² vs 1/x, the sign condition. These are the exam-hard traps.
- Q8 method 3 ("biggest top, smallest bottom, three seconds") is exactly right. More of this.

# Topic 4: Expressions — Fundamentals

## Most important points

1. **Only two guided questions** (Q1, Q2). Topic 3 has ten. The student gets almost no exam-style modelling here. Add 4–5 guided questions (see section 4).
2. **The most common exam use of the formulas is missing:** "Given a + b = 7 and ab = 10, find a² + b²" or "given a − b = 3 and a + b = 5, find a² − b²". Not in the video, not in practice.
3. **Ideas used before they are taught:**
   - q-103, q-104: a · a³ = a⁴ (adding exponents). Slide 4 shows only a · a = a².
   - t4-1-3: factoring x² + 8x + 15 by "sum 8, product 15". Never taught in this topic.
   - q-101: roots as "like terms". OK, but say it in the video once (slide 3).
4. **Board missing items.** Slide 2: the teacher writes under "x" and "−x", but the board shows only 5x. Slide 4: "Under them write 5a and 6a²" — "2a + 3a" and "2a · 3a" are not on the board. The weak student will not know what "them" is.

## 1. Coverage — missing or too thin

- **Using identities to find a value** (a + b and ab → a² + b²; a² − b² from a + b and a − b; (x + 1/x)² = x² + 2 + 1/x²). High-frequency NITE type. Missing.
- **Difference of squares with numbers** (97 × 103, 51² − 49², 1001² − 999²). Only in the memory card (48·52) and t4-1-5. Not in the video. Quick and loved by the exam.
- **Order of operations with a coefficient: 3(x + 3)²** — square first, then multiply. Only in the q-112 solution. Common trap (students write (3x + 9)²). Put it on a slide.
- **Two brackets with negatives**: slide 7 shows only (x + 4)(x + 3). No example like (x − 4)(x + 3). Sign errors live here.
- **A whole bracket as a common factor**: said on slide 8 ("even a whole bracket") but no example. Only in practice t4-1-6.
- **(a − b)² = (b − a)²** and (a − b) = −(b − a): only a card tip. (Topic 5 slide 5 covers opposite brackets — add a pointer.)
- **(a + b)² + (a − b)² = 2(a² + b²)** — twin of Q1. Mention it in the Q1 solution.
- **−x² vs (−x)²** with plugged-in negative values. May be in the powers topic; if not, add here.

## 2. Teaching quality per level

**Weak student**
- Slides 2–8 are clear and well paced. Good: "every minus sign travels with the term after it", "the minus flips everything".
- Slide 12 (formulas backward) is quick. Give a 3-step checklist on the board: (1) are the first and last terms squares? (2) is the middle 2·(first)·(last)? (3) the sign of the middle gives + or −.
- Q1 video: "equal terms CANCEL; REDUCING is different" — good, but confusing mid-solution. Move to slide 3 or slide 8.
- Needs the exponent rule (a · a³ = a⁴) before q-103.

**Medium student**
- Needs more guided exam questions. With only Q1–Q2, the plug-in check is seen twice only.
- Plug-in rule is missing: avoid a = b, avoid 0 and 1 (in Q1, a = b would make (a − b)² = 0 and hide errors). Say it.

**Strong student**
- Slides 2–7 are too slow for this student, but the intro says "review it fast". Acceptable.
- Wants: numeric shortcuts (97 × 103), the "given a + b and ab" type, and seeing the formulas inside bigger questions. None of these are in the video.

## 3. Correctness

- All 28 keys are correct (Q1–Q2 and 26 practice).
- **Style error:** t4-1-1 choices "1x + 8y", "1x + 2y". Slide 2 teaches that the 1 is hidden. Write "x + 2y".
- Board/SAYS mismatch on slides 2 and 4 (see top point 4).
- t4-1-2 and several extras have one-line solutions ("Expand both products and collect like terms"). For weak students show the line: 3x + 12 − 2x − 2 = x + 10.

## 4. Methods to add or teach differently

- **Slide 11 → add a numbers line:** "98 × 102 = 100² − 2² = 9996". 20 seconds.
- **New slide after 12 — "Find the value without finding x":** a + b = 7, ab = 10 → a² + b² = 49 − 20 = 29. Also a² − b² = (a − b)(a + b).
- **Slide 7:** second example with a minus: (x − 5)(x + 2) = x² − 3x − 10.
- **Slide 9:** add 3(x + 3)² — "power first, then the 3".
- **Slide 4:** add a · a³ = a⁴ ("count the a's"), or point to the powers topic.
- **New guided questions (suggested):**
  1. x + y = 6, xy = 5 → x² + y² = ? (26)
  2. 51² − 49² = ? (200)
  3. (a − b)² where the choices include (b − a)² — "which are equal?"
  4. Simplify (x² − 9)/(2x + 6) — factor then cancel.
  5. (a + b)² + (a − b)² = ? — then plug-in check.

## 5. Practice

- 26 items: enough in number, but almost all are drill level (one step). Exam-hard items: only q-106 and maybe q-110.
- **Repetition:** q-107, q-108, q-109, q-110 are four near-identical minus-bracket items. q-111, q-112, q-114 are the same skill. q-117, q-118 the same. Keep one or two of each, add harder ones.
- Practice does use the taught formulas. But "plug in to check" is never needed in practice — add items where plugging in is the fastest way (letters in the choices, e.g. q-106 can be checked with x = 2).
- t4-1-3 uses untaught trinomial factoring — move it to the quadratics topic or teach it first.

## 6. Verdict

- **Weak:** will expand and factor simple expressions; will trip on q-103/q-104 (exponents) and on sign errors in two brackets.
- **Medium:** will know the formulas; not yet ready for exam questions that use them indirectly.
- **Strong:** will finish quickly but meets none of the exam-level uses (value from a + b and ab, number shortcuts).

**Top 3 changes**
1. Add 4–5 guided exam-style questions, including "given a + b and ab, find a² + b²" and a number difference-of-squares.
2. Add the missing small rules to the video: a · a³ = a⁴, 3(x + 3)² order, a two-bracket example with negatives.
3. Cut repeated drill items (q-107–q-110, q-111/112/114) and replace with harder, plug-in-friendly items; fix t4-1-1 "1x" and slides 2/4 board text.
