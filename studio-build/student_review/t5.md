### Q 1 (q-135): \(\dfrac{12}{\dfrac{1}{\frac{1}{3}+\frac{1}{6}}}=\ ?\)
  (1) \(3\)
  (2) \(6\)
  (3) \(9\)
  (4) \(12\)
  correct: 1
  solution: Inside out: 1:3 + 1:6 = 2:6 + 1:6 = 1:2 . Then 1 : (1:2) = 2 . Finally 12 : 2 = 6 .

### Q 2 (q-136): Given: \(p \ne  q\). \(7 - \frac{p - q}{q - p} = ?\)
  (1) \(6\)
  (2) \(8\)
  (3) \(7\)
  (4) \(-8\)
  correct: 1
  solution: Since q − p = −(p − q) , the fraction (p − q):(q − p) equals −1 . So the expression is 7 − (−1) = 8 .

### Q 3 (q-137): \(\left(c + d\right)\left(t - 3\right) + \left(c + d\right)\left(t + 3\right) = ?\)
  (1) \(2t(c+d)\)
  (2) \(2(c+d+t)\)

  (4) \((c+d+t)\)
  correct: 0
  solution: Factor out the common bracket: (c + d)[(t − 3) + (t + 3)] = (c + d)(2t) = 2t(c + d) .

### Q 4 (q-138): What is the value of the expression: \({\left(a + b + c + d\right)}^{2} - {\left(a + b - c - d\right)}^{2} = ?\)
  (1) \({a}^{2} + {b}^{2}\)
  (2) \(4\,\left(a + b\right)\left(c + d\right)\)
  (3) \(2\,\left(ab - cd\right)\)
  (4) \({c}^{2} + {d}^{2}\)
  correct: 1
  solution: Group: let A = a + b and B = c + d . The expression becomes (A + B)² − (A − B)² = (A² + 2AB + B²) − (A² − 2AB + B²) = 4AB = 4(a + b)(c + d) .

### Q 5 (q-125): \(\left({18}^{2} - 18\right) - \left({17}^{2} + 17\right) = ?\)
  (1) \(1\)
  (2) \(0\)
  (3) \(18\)
  (4) \(17\)
  correct: 1
  solution: Factor each bracket: 18² − 18 = 18(18 − 1) = 18 · 17 , and 17² + 17 = 17(17 + 1) = 17 · 18 . The two brackets are the same number, so their difference is 0.

### Q 8 (q-128): If ___ then the value of the expression \(\frac{\left|x\right|}{x} + 5\) equals ___.
  (1) \(3\) ; \(0 < x\)
  (2) \(4\) ; \(x < 0\)
  (3) \(5\) ; \(x < 0\)
  (4) \(7\) ; \(0 < x\)
  correct: 1
  solution: If x < 0 then |x| = −x , so |x|:x = −x:x = −1 , and the expression equals −1 + 5 = 4 . (If 0 < x , |x|:x = 1 and the expression equals 6 — which matches no " 0 < x " choice, confirming the negative branch is the one being tested.)

### Q None (q-122): \(\frac{8}{\frac{1}{\frac{1}{2} + \frac{1}{4}}} = ?\)

### Q None (q-123): Given: \(m \ne  n\). \(5 - \frac{m - n}{n - m} = ?\)
