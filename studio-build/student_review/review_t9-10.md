## Topic 9: Roots — Fundamentals

### Most important points
1. **The 15 questions use tools the video never teaches.** There are no worked-solution videos, so a weak student meets these cold:
   - **q-235** ∛(5⁶) and **q-236** 81^(1/4) need the general rule ⁿ√(aᵐ) = a^(m/n). Slide 8 shows only √a = a^(1/2) and ∛a = a^(1/3). Put ⁿ√(aᵐ) = a^(m/n) on the board with one example.
   - **q-243 / q-244** (3√7 = √63, 3∛2 = ∛54): "bring a number inside the root" is never shown. Add it to slide 4 as the reverse of "pull out squares" (square it for √, cube it for ∛).
   - **q-247** and **practice-5**: solving by "square both sides" is taught only in Topic 10 (slide 9). Move these to T10, or add one line on it here.
   - The memory-card tip "6/√3 = 2√3 — ignore the root, then put it back" is taught only in T10 slide 3.
2. **q-242 is not exam material.** A root with index 2.5 never appears on NITE. The long explanation in the stem shows it is artificial. Replace it with a real root-of-a-root question: √(√81) = ? (= 3), or ⁴√(x⁸) for x > 0.
3. **The key NITE trap for roots is missing: numbers between 0 and 1.** √0.09 = 0.3, √0.9 ≈ 0.95 (not 0.3), and for 0 < x < 1: √x > x > x². This is a frequent exam trap in "which is greatest?" questions. It needs one slide and 2–3 questions.

### 1. Coverage — missing or thin
- Roots of decimals and fractions: √0.04 = 0.2, √(1/9) = 1/3, and "√0.4 ≠ 0.2". Not covered.
- Order: for 0 < x < 1, √x > x. For x > 1, √x < x. Not covered.
- Comparing roots:
  - **By squaring** (4√3 vs 5√2): used in T10 q-287 but never taught.
  - **Different indices** (√3 vs ∛5: raise both to the 6th power) is missing.
- Conjugates: (√a + √b)(√a − √b) = a − b, and 1/(√2 − 1) = √2 + 1. NITE uses these. Not taught here or in T10.
- Square of a sum: (√a + √b)² = a + b + 2√(ab). The T10 q-287 solution uses it but it is never taught.
- Domain: "for which x is √(x − 3) defined?" is only said in passing (slide 2).
- √(a²b) = |a|√b, and estimating a root between two integers: only one practice question (practice-7).

### 2. Teaching quality per level
- **Weak:**
  - Lost at q-235, q-236, q-243, q-244 and q-247 (see point 1).
  - Slide 3 (√x² = |x|) is correct but abstract. One more example with x < 0 on the board would help (practice-3 tests it).
  - The colon for division ("√(75 : 3)", "1:4" in q-241) can read as a ratio in English. Use "÷" or a fraction bar.
- **Medium:** Follows the video well. The first 9 questions (q-233 to q-241) are all one-step drills of the same rules. Good for building habit, but there is no mixed or multi-step question before the practice set.
- **Strong:**
  - Bored by q-233 to q-241.
  - Nothing is exam-hard: no comparison with traps, no 0-to-1 trap, no conjugate.
  - q-245 (smallest of π, 3, ∛30, √7) is the only good "exam-style" item.

### 3. Correctness
- All keys are correct (q-233 to q-247 and the extra practice 1–7).
- q-242: correct, but a non-standard concept with an awkward stem (see above).
- q-245 solution: fine (∛30 ≈ 3.107 < π).
- Display: every question shows as "Q None". This looks like a missing number in the export.

### 4. Methods and tricks to add
- **Slide 4:** "Pull out the LARGEST square. Check: is the number left inside still divisible by 4, 9 or 25?"
- **New slide, "Roots of small numbers":** √0.09 = 0.3 (count decimal places: half of them). Add the rule √x > x for 0 < x < 1 with a number line.
- **Compare by squaring:** "To compare a√b and c√d, square both." Example: 4√3 = √48 vs 5√2 = √50.

### 5. Practice

### 6. Verdict
- **Weak:** Partly. Basic simplifying is fine, but they will fail fractional-power and "bring inside" questions until these are taught.
- **Medium:** Yes for standard simplify / multiply / divide. No for comparison and 0-to-1 traps.

## Topic 10: Laws of Exponents & Roots — Techniques

### Most important points
1. **The biggest NITE exponent trap is missing: sums of powers.** 2¹⁰ + 2¹⁰ = 2¹¹; 3ˣ + 3ˣ + 3ˣ = 3ˣ⁺¹; 2ˣ⁺² − 2ˣ = 3·2ˣ; and "2ˣ + 2ˣ ≠ 4ˣ". This appears on almost every exam. It needs one slide ("take out the smallest power as a common factor") and 3–4 questions.
2. **Slide 9 (root equations) is never solved.** It sets up √(x+7) = x − 1 and stops. The example has ugly roots, (3 ± √33)/2, which is probably why. The student never sees a fake solution thrown out. Use √(x+2) = x instead:
   - Square: x² − x − 2 = 0, so x = 2 or x = −1.
   - Check: −1 fails (√1 = 1 ≠ −1).
   This one example teaches the whole slide.
3. **Q2 video, slide 2, gives bad advice:** "the exam often places a number like that in its own position … don't be surprised". This is not a real pattern, and it invites guessing by position. Delete it.

### 1. Coverage — missing or thin
- **Sums of equal powers / common factor of powers** (see above). Missing entirely.
- **Comparing powers with different bases:** 2³⁰ vs 3²⁰ means (2³)¹⁰ vs (3²)¹⁰, so compare 8 vs 9 by making the exponents equal. Only the "same base" method is taught (slide 4). The extra "which is greater" items (t10-2-6, t10-3-6) only use same base.
- **Bases between 0 and 1:** (1/2)ˣ > (1/2)ʸ means x < y (the direction flips). Missing.
- **Negative bases:** (−2)⁴ vs −2⁴, and the sign of (−a)ⁿ by parity. Probably in T8, but not revisited in the mixed practice here.
- **Same exponent, different bases:** aˣ·bˣ = (ab)ˣ is used in q-281, but never shown in the video.
- **Equation types:**
  - 2ˣ = 3ˣ ⇒ x = 0 (only an exponent of 0 works) is missing.
  - Unit digit of a power (7¹⁰⁰): usually taught in number theory. OK if it is covered there.
- **Conjugates and (√a + √b)²:** see T9. q-287 needs these.

### 2. Teaching quality per level
- **Weak:**
  - Slides 2–3 are excellent: slow, two methods, and a clear shortcut.
  - Slide 5 (negative exponents) is fast. "Flip the base" plus one example is thin for a weak student before Q1, which has 2⁻⁶ ÷ 2⁻⁴. Add one line: "−6 − (−4): minus minus is plus".
  - Slide 9 leaves them with no solved example (see above).
- **Medium:**
  - Good. The five guided questions match the five techniques, and the videos show two methods.
  - A gap: after Q5 they may divide by x when x = 0 is allowed. q-247 in T9 is exactly that case (2 solutions). Link them: "If x ≠ 0 is NOT given, factor — don't divide."
- **Strong:**
  - Slides 6–7 (two methods for adding roots) are long for them.
  - The practice has some real exam items: q-281, q-282, q-284, q-287. But there is no sums-of-powers trap and no comparison of different bases/exponents.
  - q-277 (x = y = 8) is trivial.

### 3. Correctness
- **All 47 keys are correct** (Q1–Q5, q-253 to q-287, and extra sets t10-2 and t10-3).
- **q-278:** the condition "Given: 0 < a, c." is garbled. Write "a > 0, c > 0".
- **q-287:**
  - The solution is right but takes a long road: (√5 + √20)² = 45. Simpler: √20 = 2√5, so the sum is 3√5 = √45 < √49 = 7. This also matches what the topic taught.
  - The stem "Which of the following statements is necessarily true?" would read better as "Which of the following is correct?"
- **q-276:** "Given 0 < x" is not needed. Harmless.
- **Slide 9:** the example is not finished (see above). Not an error, but it is a teaching hole.

### 4. Methods and tricks to add
- **Plug in the answers.** For every exponential or root equation (Q3, q-257, q-258, q-266, q-267), say once: "4 choices — try them, often faster than algebra." It also removes fake solutions in root equations. Add this as Method 2 on slide 8 or 9.
- **Choose easy values.** q-268, q-270, q-284: put x = 2 (or a = 2) and test the choices. Show this once in the q-268 solution.
- **Equal exponents for comparison** (2³⁰ vs 3²⁰): a new slide after slide 4.
- **Common factor of powers:** 2ˣ⁺³ + 2ˣ = 2ˣ(8 + 1) = 9·2ˣ. A new slide after slide 5. It uses the same "take out a common factor" idea as slide 7, so it fits well there.
- **Q1:** the "pair the families" method (Q1 video, slide 3) is a great shortcut. Name it on the recap slide.

### 5. Practice
- **Amount:** 47 questions is plenty.
- **Spread:** easy to medium. The only exam-hard items are q-281, q-284 and q-287.
- **Repetitive:** extra sets t10-2-1…7 and t10-3-1…7 are the same seven templates with new numbers. Keep one set. Replace the other with:
  - Sums of powers: 2¹⁰ + 2¹⁰ + 2¹⁰ + 2¹⁰ = ?
  - Different-base comparison: 2³⁰ vs 3²⁰
  - Base between 0 and 1: (0.5)ˣ > (0.5)³ ⇒ ?
  - A root equation with a fake solution: √(x+2) = x
  - Conjugate: 1/(√2 − 1)
- Also near-duplicates: q-262, q-263 and q-283 (three plain "simplify √n"), and q-276 / q-277.

### 6. Verdict
- **Weak:** Yes for same-base powers, dividing by a root, and simple root equations. No for sums of powers and fake solutions.
- **Medium:** Mostly yes. They will miss sums-of-powers and comparison questions.
- **Strong:** Not fully. The hardest exam exponent traps (sums of powers, comparing different bases, bases < 1) are not taught.

**Top 3 changes:**
1. Add a "sums of powers" slide (common factor: 2ˣ + 2ˣ = 2ˣ⁺¹, 2ˣ⁺² − 2ˣ = 3·2ˣ) plus 3–4 questions.
2. Replace the slide 9 example with √(x+2) = x and solve it fully, showing the fake root thrown out. Add "plug in the answers" as a second method. Delete the "answer in its own position" remark in the Q2 video.
3. Replace the duplicate extra set with exam-hard items: different-base comparison (2³⁰ vs 3²⁰), base between 0 and 1, conjugates. Fix the q-278 wording.
