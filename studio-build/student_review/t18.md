### Q 1 (q-512): A, B, C and D are letters representing digits from 0 to 9. Given: \(AB + CB = DDB\) (with AB and CB being two-digit numbers and DDB being a three-digit number, each letter being the digit in that position). \(A + C + D = ?\)
  (1) \(12\)
  (2) \(11\)
  (3) \(10\)
  (4) \(13\)
  correct: 0
  solution: Expand by place value: AB + CB = (10A+B) + (10C+B) = 10(A+C) + 2B , and DDB = 110D + B . Equating: 10(A+C) + 2B = 110D + B , so 10(A+C) + B = 110D . The left side ends in digit B while 110D ends in 0, forcing B = 0 . Then A + C = 11D ; since A + C ≤ 18 , we get D = 1 and A + C = 11 . So A + C + D = 11 + 1 = 12 . Example: A=5 , C=6 : 50 + 60 = 110 = DDB with D=1 , B=0 ✓.

### Q 2 (q-513): A, B and C are letters representing digits from 0 to 9. Given: \(BA \cdot  A = CA\) (BA and CA are two-digit numbers). What could the value of A be?
  (1) \(6\)
  (2) \(3\)
  (3) \(2\)
  (4) \(0\)
  correct: 0
  solution: The product BA·A must end in the digit A, so A·A must end in A. Only the digits 0, 1, 5, 6 satisfy this (0, 1, 25, 36). Among the choices, 3 and 2 fail immediately ( 3·3=9 ends in 9; 2·2=4 ends in 4). A = 0 would make the product 0, which is not a valid two-digit CA. A = 6 works: take B = 1 , then BA = 16 and 16 · 6 = 96 = CA with C = 9 ✓.

### Q 3 (q-514): A and B are letters representing digits. The result of the expression \(AB + BA\) is necessarily divisible by —
  (1) \(9\)
  (2) \(6\)
  (3) \(11\)
  (4) \(4\)
  correct: 2
  solution: Expand: AB + BA = (10A+B) + (10B+A) = 11A + 11B = 11(A+B) — always a multiple of 11, whatever the digits are. Examples: 47 + 74 = 121 = 11·11 ; 62 + 26 = 88 = 11·8 . Divisibility by 9, 6 or 4 fails in these examples (121 is divisible by none of them).

### Q 4 (q-515): A, B and C are letters representing digits between 0 and 9. Given: \(ABC + AB = CCC\) (ABC is a three-digit number, AB a two-digit number, CCC a three-digit repdigit). \(B = ?\)
  (1) \(1\)
  (2) \(5\)
  (3) \(9\)
  (4) \(0\)
  correct: 3
  solution: Expand: ABC + AB = (100A+10B+C) + (10A+B) = 110A + 11B + C , and CCC = 111C . Equating: 110A + 11B + C = 111C , so 110A + 11B = 110C , and dividing by 11: 10A + B = 10C . The left side ends in digit B, the right side ends in 0 — so B = 0 , and then A = C . Verify: with A = C = 2 , B = 0 : 202 + 20 = 222 ✓ (works for any A = C , but B is forced to 0).

### Q 5 (q-516): A, B and C are letters representing digits between 0 and 9. Given: \(AAA - 37 = BC\) (AAA is a three-digit repdigit, BC a two-digit number). \(B + C = ?\)
  (1) AA
  (2) AB
  (3) AC
  (4) BC

### Q 6 (q-517): A, B and C are letters representing digits between 0 and 9. Given: \(AB \times  AB = 6\,CB\) (AB squared is a three-digit number whose hundreds digit is literally 6). Which of the following could be the value of the expression \(B - A\)?
  (1) \(4\)
  (2) \(6\)
  (3) \(7\)
  (4) \(8\)
  correct: 0
  solution: For the square to have hundreds digit 6 it must lie in [600, 699], so AB ∈ {25, 26} ( 24² = 576 is too small, 27² = 729 too big). Self-consistency: the units digit of AB² must equal B. AB = 25 : 625 ends in 5 = B ✓, giving B − A = 5 − 2 = 3 (not among the choices). AB = 26 : 676 ends in 6 = B ✓, giving B − A = 6 − 2 = 4 — matches choice (1). (With A=2 , B=6 , C=7 : 26 × 26 = 676 ✓.)

### Q 7 (q-518): A, B and C are letters representing digits between 0 and 9. Given: \(\frac{CBA}{AA} = 13\) (CBA is a three-digit number, AA a two-digit repdigit). \(A + B + C = ?\)
  (1) \(16\)
  (2) \(13\)
  (3) \(12\)
  (4) \(14\)
  correct: 1
  solution: CBA = 13 × AA = 13 × 11A = 143A . The units digit of CBA must equal A, and 143A ends in the units digit of 3A ; so 3A must end in A, i.e. 2A ends in 0, forcing A = 5 ( A = 0 is invalid — AA wouldn't be a two-digit number). Then CBA = 143 × 5 = 715 : C = 7 , B = 1 , A = 5 ✓ (units digit 5 = A ). Verify: 715 : 55 = 13 ✓. A + B + C = 5 + 1 + 7 = 13 .
