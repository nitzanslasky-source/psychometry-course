# Topic 25: Averages

**Depends on:** fractions (T2–T3: p05, p04, the "3/2 = 6/4" step in Q3); equations (T6–T7: Q2 method 1, Q8 method 1); inequalities (T12: p09, p10); "necessarily true" thinking (T20: p02, p10, p12); ratios (T22: the see-saw, "6 : 9 = 2 : 3", p19, p20).
**Needed by:** T26 (p09 is an average rate); T27 Motion (average speed is a weighted average — by time, not by distance); mixture questions in general.

## 1. Coverage — what is missing

- **"Balance" for more than two numbers (sum of deviations = 0).** The course uses it in Q2 method 2, p07, p08 and p13 solutions, but only teaches it for two numbers. Add one slide after "Towers of blocks": "Above-average amounts = below-average amounts." Example: scores 86, 93, 95, ? with average 90 → +3 +5 −4 = +4, so ? = 86. This is the fastest method on the exam.
- **Find the number of values from a change.** Classic NITE: "A group's average is 20. A new value 30 joins and the average becomes 22. How many were there?" (Answer: the new value is 8 above the new average; each old value rose by 2 → 4 old values.) Not taught, not practised.
- **Change every value** (+k → average +k; ×k → average ×k; "ages in 5 years"). Appears only in p24, never taught. Add to slide 6 "One value changes" as a second line.
- **Evenly spaced / consecutive numbers:** average = middle term = (first + last)/2. p25 even says "Consecutiveness is not needed" — a missed chance. Slide 2 (symmetric group) is the right place.
- **Maximum / minimum under constraints** (p14, p15): no guided example. Add one with a trap: "distinct positive integers" (then the others are 1, 2, 3, 4, not 1, 1, 1, 1).
- **Averaging averages of unequal groups** is taught (slide 7). Good. But also add the trap in words: "Average of 50 and 70 is 60 only if the groups are equal."
- Median: only if the course wants full coverage; NITE uses it rarely. Low priority.

## 2. Teaching quality per level

**Weak student**
- Q3 (six pair-averages) comes before weighted averages and is very abstract. The plug-in method saves it, but put a note: "If this is hard, go straight to method 2."
- The see-saw rule "distances = weights, flipped" is clear on slide 5. But the weak student will not know which part goes on which side. Add one sentence to slide 6: "The heavy side gets the SMALL part."
- The colon ":" is used for division and for ratio in the same topic: "(124+246):5=74" (Q7), "81:4" (p22), "(204+92):4" (p23), next to "2 : 3" weights. In a ratio topic this is confusing. Use ÷ or a fraction bar for division.
- "so" is used as "therefore" in the middle of sentences: "Ava and Ben must so total 168" (p07), "Ella so has" (p16), "The sum of pair averages is so" (Q3), "The five newcomers so total" (p26). Write "so Ava and Ben total…" or "therefore".

**Medium student**
- Good: every guided question has formula + shortcut. Q7 method 2 (eliminate by the midpoint, then ratios) is excellent.
- Gap: the "balance" and "number of values from a change" types (above). Without them, a medium student will write long equations.

**Strong student**
- The first video (slides 2–4) is slow for them, but short. Fine.
- Missing hard traps: "average rises when a value is removed" logic (p17 is good — put a guided one), weighted average with three groups, and letter questions like p20. Give a guided "which information is enough" question.

## 3. Correctness

- All keys correct (Q1–Q8, p01–p27).
- **Q3 choices:** choice (2) is worded "6 times the average of the four numbers", the others "N times their average". The different wording points to the answer. Use the same wording for all four.
- **p11:** "b = a + 2" together with "average = 3a" fixes a = 0.5, b = 2.5. Then "in terms of b" is strange, and the solution says "We did not need the gap of two". Remove "b = a + 2" (and add "a, b ≠ 0"), or ask for a number.
- **Q2 solution text** is correct but gives no method name; the video's "balance point" is much better. Put one line of it in the text.
- p06, p08 and p12 all test the same idea (average equals one of the values → all equal / equal gaps). Not wrong, but repetitive.

## 4. Methods and tricks to add

- **Balance / deviations** slide (see Coverage) — top priority. Use it again in a guided question.
- **Assumed average:** "Pick a round number near the values, average only the differences." (e.g., 97, 102, 104, 99 → base 100: −3 +2 +4 −1 = +2, ÷4 → 100.5.)
- **Midpoint elimination** (Q7 method 2) should be a named rule on the memory card: "Two groups: the answer is on the side of the bigger group."
- **Plug-in with all values equal** (Q3 method 2) — add to the memory card as a tip, with the warning: "all-equal can make two choices match; then try other numbers."
- **Weighted average by 'extra per item'** (Q8 solution text, p27): "Start with everyone at the low value, count the extra." This is a third method, clearer than both. Name it in the Q8 video.

## 5. Practice

- 27 questions — enough.
- **Order:** p21–p27 are the easiest (direct sum/average) but come last, after the inequality questions p09–p11. Move p21–p27 to the start.
- p23 is almost Q5 (same scores 68 and 92, weight 3 instead of 2). Change the numbers.
- p05 is only fraction arithmetic. Replace with a "number of values" question.
- Missing in practice: balance with 4+ numbers, find n, max/min with distinct integers, evenly spaced numbers.

## 6. Verdict

- **Weak:** Can do sum = number × average and simple weighted averages; will get lost on balance-type and "necessarily true" questions.
- **Medium:** Reliable on standard questions; slow on types not taught (find n, balance, change all values).
- **Strong:** Learns the see-saw fast and likes it; still missing the harder traps (distinct integers, find n, three groups).

**Top 3 changes:**
1. Add a "balance / sum of deviations = 0" slide and a guided question; add the "find the number of values" type.
2. Teach "change every value" and "evenly spaced → middle term"; add a guided max/min question with distinct integers.
3. Reorder practice (easy first), fix Q3 choice wording and p11, and replace ":" division and "so" in solutions.

# Topic 26: Work and rates

**Depends on:** fractions — adding and dividing (T2–T3: Q2, Q3, p14, p22, p26); equations (T6–T7: Q6); letters in answers (T20: Q1, p12, p17); ratios / proportion (T22: team questions, p15, p20); percentages (T23: p25); averages (T25: p09); **circle area (T33: p10 — far ahead in the course).**
**Needed by:** T27 Motion (same formula: distance = speed × time; "towards each other" = add rates). Teach T26 right before T27.

## 1. Coverage — what is missing

- **A worker joins or leaves in the middle** (p22, p23, p26). This is one of the most common NITE rate questions, and there is no guided example. Add one: "A alone for 3 hours, then B joins" solved with worker-hours or fractions.
- **Two workers — shortcut formula.** Together time = ab/(a+b). (Q3: 4·6/10 = 2.4 h.) Strong students expect it. Also: "two equal workers → half the time".
- **Percent change in rate → time.** Rate +25% → time × 4/5 (−20%, not −25%). Only p25, never taught. Add one line to slide 5 "Three relationships": "Rate × 5/4 → time × 4/5."
- **Average rate over two jobs** (p09): the average is total work ÷ total time, not the average of the rates. Link it to T25; it is also the key trap in T27.
- **Range check** as a rule: together time is less than the fastest alone, and more than the fastest ÷ 2 (if the other is slower). It is used in Q3 and Q8, but not written on the memory card.
- Letter questions: Q1, p12, p17 exist. Good. Add a short "plug in numbers for letter answers" line in the first video.

## 2. Teaching quality per level

**Weak student**
- Video 1, slide 2: "Use the triangle. Cover the one you want." The triangle is never drawn. Only "Rate × Time = Work" is on the board. Draw it.
- Q1 video, method 1 ("Identical ratios"): "In row 2 write 3x", "row 3" — no table has been set up on the board. Set up the table (samples | minutes) first. Method 2 is called **"Triple value"** — this means nothing in English (translation of "rule of three"?). Call it "Cross-multiply". "Cross-multiply" itself is not explained.
- The V method (Q4) is shown only by example: "a V through 5, 72, 4". Say the general rule on the board: "top-left, bottom-middle, top-right; divide by the other two. Works when the blank is in row 2." "Turn the V upside down" needs one example.
- Team video slide 4: "Team questions need more time — so the row ends with Time" does not help memory. Just say: "Work always in the middle."
- ":" is used for division ("rate = 18 : 3", "? = 4y · 3x : y", "96:4") and for ratio ("E:C", "1 : 5"). Use ÷ for division.
- Q2 wording: "One inlet fills a tank in 8 hours. An identical inlet has the same rate." Clumsy. Better: "Two identical inlets each fill the tank in 8 hours."
- Names: Q4 method 3 says "worker-hours"; the next video calls it "Work time". Use one name ("worker-hours") everywhere, including the memory card.

**Medium student**
- The two methods for different workers (equalize times vs. add rates) are both shown — good. But the memory card does not say when to use which. Add: "Nice common multiple → equalize times. Otherwise → fractions."
- Gap: no guided question with phases of different-rate workers (see Coverage).

**Strong student**
- Written solutions are very long: Q1 has 4 paragraphs, Q4 has 5, Q10 has 4. The third paragraph of Q1 is general theory, not a solution. Cut each to 2–3 short lines; the videos already explain.
- Q8 method 2 (estimate) and Q9 method 2 (insight) are exactly what they want. More of that.
- Missing: ab/(a+b), rate % change, harder joins/leaves questions.

## 3. Correctness

- All keys correct (Q1–Q11, p01–p27).
- **p26:** "A can be emptied by drain A in 9 minutes…" reads as "Can A…" or "A can [verb]". Write "A container is emptied by drain A in 9 minutes…".
- **p01:** "How many folding or labeling actions" is awkward English. Write "How many boxes do they fold and label in total?"
- **p10** needs circle area (T33). Keep it only if T33 comes first; otherwise move it or use a rectangle.
- **p12:** "2q envelopes" mixes the letter for minutes into the number of envelopes. Legal, but looks like a typo. Use "2p envelopes" (answer 2q) or a new letter.
- Q6 video: "Rule: give to the poor one" (multiply the smaller side). Correct, but add the check "then both sides are equal"; weak students may misread "poor".
- "so" used as "therefore" mid-sentence: "We so need" (Q10), "They so cover" (Q8), "One order so takes" (Q3), "One worker so needs" (p13).

## 4. Methods and tricks to add

- **Guided "joins/leaves" question** after Q5, solved with worker-hours: "Total job = 84 worker-days. Done: 24. Left: 60. ÷ 4 workers."
- **ab/(a+b)** and "equal workers → half" on the memory card, after Q3.
- **Range check** (after Q8): "Together < fastest alone; together > fastest ÷ 2." Use it to eliminate first.
- **Pick a job size = LCM** (Q2 method 2, 24 units) — make it the default for weak students, before fractions. Put it on the memory card.
- **Rate change in % → time:** one board line + a guided or practice question.
- **Draw the triangle** on slide 2.

## 5. Practice

- 27 questions — enough, good spread.
- Repetitive: p02 is almost Q1 (same answer choices 12x, 7x, 4x/3). p14 is Q9 with other numbers. p15 is Q6 with other numbers. p11, p21 are simple pipe questions of the same kind. Replace two of these with "joins/leaves with different rates" and "rate % change".
- Order: p02, p06, p11, p21, p24 are easy and spread through the set. Put easy ones first.
- Practice does use the taught tools (worker-hours, V method, combined rate). Good.

## 6. Verdict

- **Weak:** Will solve single-worker and simple team questions; will get lost on the V method (no general rule) and on joins/leaves questions.
- **Medium:** Reliable on "together" and team questions; unsure on phases and rate-% questions.
- **Strong:** Solves most questions; bored by long text solutions; wants ab/(a+b) and harder traps.

**Top 3 changes:**
1. Add a guided "worker joins / leaves in the middle" question (with worker-hours), and a rate-% → time line.
2. Fix the unclear boards: draw the triangle, set up the table in Q1 and rename "Triple value", write the general V rule.
3. Shorten the written solutions, replace ":" division and "so", fix p26/p01 wording, and deal with p10's circle-area dependency.
