# Topic 19: Defining a New Operation

**Depends on:** order of operations and substitution (T1); fractions (T2–T3: Q13, Q15, q-561); factoring and the square formulas (T4–T5: Q1 method 2, Q11, q-574); equations and the zero product (T6–T7: slide 9, Q8, q-562, q-575, q-566); exponents and roots (T8–T11: Q2 method 2, Q10, Q12, q-557, q-559). Q15's "a negative power flips floors" uses the word "floors" from T11. Also: inequalities (T12: Q15, q-573); absolute value (T13: q-563); prime factorization (T14: Q16); remainder (T15: q-576); odd/even (T16: Q5); letters as digits (T18: Q14, q-567, q-571).
**Needed by:** T21 Patterns (step-by-step sequences look like the "circular" rules). T20's must/can/cannot table is needed HERE: Q9, Q15, Q16, q-573, q-574 ask "necessarily true" before T20 teaches it.
T19 uses almost all of T1–T18, so its place at the end of algebra is right.

## 1. Coverage — what is missing

- **Putting an expression or a negative number into the definition.** This is very common on the exam. Example: ◆(x) = x² − 2x, find ◆(x+1) or ◆(−3), with answer choices in x. The lesson only puts in positive numbers. Q12/Q13 put in letters, but only single letters. The weak-student trap is forgetting brackets: writing x+1² − 2x+1 instead of (x+1)² − 2(x+1). Add a slide after slide 3: "Substitute with brackets — always," with one example of a negative number and one of an expression.
- **Definitions in words.** Exam examples: "the larger of…", "the remainder of…", "the number of divisors of…", "the sum of the digits of…". The **integer part** (the largest integer not bigger than x) is a classic and is missing completely. In this topic they appear only as questions (Q16, q-558, q-571, q-576), with no method taught. Add a short slide: "A definition in words? Write 2–3 quick examples before you touch the choices." Q16 method 1 already does this, so make it a named step.
- **Solving ◆(x) = k when the rule has conditions.** You must try both branches and throw out a result that does not match its branch. Example: odd → 2x, even → x² − 7, and ◆(x) = 9: the even branch gives x² = 16, x = 4 (even, OK); the odd branch gives x = 4.5 (not an integer, rejected). This trap is not taught.
- **Order / grouping questions** ("for which operation is a★b = b★a always?"). Slide 8 shows one example only. Add the rule: one counterexample is enough to say "not always". To say "always", swap the letters in the algebra.
- **Plug-in dangers for "necessarily true" choices.** Q9 and Q16 plug in x = 1. Say clearly: 0, 1 and a = b can make a false identity look true. If two choices survive, plug in a second, different number.
- Only mentioned in passing: "find the operation" (slide 7, Q3) has **no practice question** in the practice set.

## 2. Teaching quality per level

**Weak student**
- Slide 5, "before powers, times, divide — only brackets beat it", is abstract. The ◆(3) already has its own brackets. Clearer: "First turn every ◆(…) into a plain number. Then do the rest of the exercise as usual."
- The "Operation Patterns" video (types 2–5) shows only words on the board: no numbers for conditions, circular rules, or both sides. The weak student meets each type for the first time inside Q5–Q8. Put one tiny example on each board. The memory card already has them.
- Division is written with ":" in the solutions ("a√13:(a√7)", "a = ±1:3", "1:6"). With roots and ± this is hard to read. Use a fraction bar where possible.
- Q15 video: "A negative power flips floors" — "floors" is T11 slang and a weak student may have forgotten it. Say: "dividing by a fraction = multiplying by its reciprocal".
- Q13 is hard, but method 3 (plug in) saves the weak student. Good.

**Medium student**
- Q5 and Q6/Q7 are the only guided conditions and circular questions. The practice set has one real conditions question (q-565, and that one only uses the a = b branch) and one circular question (q-569). There is not enough repetition to become reliable.
- Q12 method 2: "Some students stop right here. Why?" reads as if stopping is wrong, then says stopping is fine. Say directly: "You can already stop: only choice 2 has √13 on top."

**Strong student**
- Slides 2–3 (4·6, the heart) and Q1–Q3 are slow for them. That is fine; it is short.
- Q13 method 2 ("the insight") is weak logic. "Same power on both letters → a/b or b/a" does not choose between a/b and b/a. It works only because a/b is not a choice. Better insight: the squares cancel, so the ratio = (b²a)/(a²b) = b/a in one line.
- They want harder traps: an operation applied to its own output many times (period / pattern, like Q6 method 2), ◆(◆(x)) = x questions, and "for how many x" with conditions.

## 3. Correctness

- **All keys are correct** (Q1–Q16, q-557–q-576, the 7 extras). No wrong answers.
- **q-567 is ambiguous:** the stem says "for positive integers x, y, z", but choice (2) uses y = 0. Also "Repeated inputs and appending 0 are allowed" is unclear English. Suggest: "x is a positive integer and y, z are non-negative integers."
- Q13 method 2: reasoning is incomplete (see above). Not wrong, but it cannot be used as a general method.
- Slide 5's rule ("before powers") is fine for ◆(…) notation. For infix symbols (a★b) the exam always uses brackets. Say that, and don't claim a general precedence rule.
- Extra questions: the solutions are written in words ("two plus three plus six is eleven"). This style does not match the rest. Use symbols.

## 4. Methods and tricks to add

- **"Brackets on every input"** slide (see Coverage), with a board example: ◆(x) = x² − 2x → ◆(x+1) = (x+1)² − 2(x+1).
- **Plug-in rules** (put them in the Operation Patterns recap and on the memory card): pick simple numbers, but not 0/1/equal values when testing an identity. Test a second number if two choices survive. Q1-style "factor first" (Q1 method 2) is a good speed tip; say it once in the lesson.
- **Work back from the answers** for ◆(x) = k questions (slide 9): put each choice into the rule.
- **Symmetry check:** if a definition is not symmetric (x² y below the line in Q13; 3x² + y² in Q12), circle which slot gets what before you calculate. Q12 does this in words; make it a board habit.
- **Cancellation shortcut** for ◆(k) − ◆(−k): only the odd powers survive (q-564, q-568). Teach it once in a guided video; it appears twice in practice without a lesson.

## 5. Practice

- Quantity: 20 exam-style + 7 extras. That is enough.
- Order: the 7 easy extras come **after** the hard ones. Move them to the start of the practice set.
- Spread: good in the middle, but these types are missing from practice: find-the-operation (0 questions), expression input (1: q-563), conditions (1). Nested computation repeats a lot (q-557, q-559, q-560, extras 3 and 6).
- q-562 and q-575 are really equation questions with a ◆ label. They are fine as a mix, but they don't train operation skills.
- Good ones: q-561 (cancelling product), q-570, q-574 (strong).

## 6. Verdict

- **Weak:** can do basic, nested and expression-input questions. Leaves shaky on conditions, circular rules and letter/expression substitution.
- **Medium:** will solve most exam questions. Needs more conditions and circular practice to be reliable.
- **Strong:** ready. Would like a few harder traps and a sounder Q13 shortcut.

**Top 3 changes**
1. Add a "substitute with brackets" slide (negative number and expression input) plus 2–3 practice questions with answers in x.
2. Put a small worked example on each board of the Operation Patterns video. Add practice for find-the-operation, conditions (including solving ◆(x) = k with branches) and circular rules.
3. Add a "definition in words / integer part" slide and the plug-in rules (avoid 0, 1, equal values; test a second number). Fix q-567's wording and the Q13 insight.

# Topic 20: Algebraic Understanding

**Depends on:** integers, gaps, parity, consecutive numbers (T16); inequalities and strictness (T12); exponent laws (T8/T10: Q2, q-589); common denominator (T2–T3: Q3); remainders (T15: q-583); digits (T18: q-590); absolute value (T13: extra 6); square formulas (T5: extras 2 and 7). **Pythagoras and the triangle inequality (T31, geometry — taught LATER)** for the Q3 video.
**Needed by:** T21 ("Possible vs must", "Minimum & Maximum" repeat slides 3–4 here, so cross-reference them). T19 already uses "necessarily true" (see above). Consider moving the must/can/cannot slide and memory card earlier, e.g. to T16 or T12.

## 1. Coverage — what is missing

- **Which numbers to plug in.** The lesson says "plug in numbers" but never says which. This is the core tool for must/can/cannot questions on the exam. Add a checklist slide: 0, 1, −1, a fraction between 0 and 1, a big number, and equal vs different values. Add the classic facts: for 0 < x < 1, x² < x and 1/x > 1; for negative x, a bigger absolute value means a smaller number. "Which is largest" questions with conditions on x are very common on the exam and are not covered here.
- **Counting integers in a range.** From a to b inclusive: b − a + 1. Strictly between: b − a − 1. Counting only odd or even numbers: divide by 2. q-586 and q-588 need this; it is not taught.
- **Pigeonhole principle.** q-583 needs it; it is not taught anywhere in the course (I searched). Either add a 3-line slide ("13 numbers, 12 possible remainders → two share one") or remove the question.
- **Scaling** (slide 5, Q2): only one power pair. The strong student wants the general rule: if x² = a³ then x changes by (factor)^(3/2), so 9^(3/2) = 27 and 16^(3/2) = 64. Add one board line.
- Only in passing: "cycle of ratios = 1" (slide 6). It is used in q-585 but never practised in a guided question.

## 2. Teaching quality per level

**Weak student**
- Slide 2: "There's no repeating principle I can hand you" is demotivating for a weak student. Reframe: "Three tools. Try them in this order: plug in → test the answers → algebra."
- Slide 4 is dense: gaps, chaining and strictness in three lines. Put strictness ("< 12 means ≤ 11") first, since Q1 uses it first.
- Q1 method 1: "b + c ≤ 11 − 2 = 9" skips the key step. Write it on the board: b + c = (a + b) − (a − c) ≤ 11 − 2.
- Q3 relies on Pythagoras and Pythagorean triples (T31 comes later; T16 mentions 3-4-5 once). The weak student is lost at "Pythagoras in disguise". The written solution uses pure algebra (c² = a² + b² > b², so c > b), which is easier. Lead the video with that. For choice 2, the easiest counterexample is 6-8-10 (3-4-5 doubled), not 5-12-13.
- Q3 video: "Common denominator a times b: a over b times a, b over a times b" is unclear. Write a/b = a²/(ab) and b/a = b²/(ab).
- Practice wording clashes with the must/can/cannot words just taught. q-581 says "necessarily not correct". The q-585 solution says "impossible, so certainly not necessarily correct". Use the exact table words: "cannot be true".
- The q-585 stem writes the fractions as "x:y, y:z, z:x". Use fraction bars.

**Medium student**
- There are only 4 guided questions, all hard ("A hard one" ×2, "seriously tough"). They need one medium guided example of a plain must/can/cannot question with plug-in (e.g. extra 4 or q-587) before Q1.
- Practice solutions (q-584, q-586, q-588) are algebra-first. Show the plug-in route (a = 2, a = 3) first. The medium student will actually use that.

**Strong student**
- Q2 method 2 and Q4 are quick and good. The extras (2-3, 2-5, 2-6) are too easy for them.
- Good hard ones: q-583, q-589, q-590. Add one more exam-hard counting-with-conditions question.

## 3. Correctness

- **All keys are correct** (Q1–Q4, q-581–q-590, the 7 extras).
- **Q3 video wording error:** "Two sides of a triangle are always longer than the third." It should be "The sum of any two sides is longer than the third."
- q-585 solution: the sentence "So (4) is impossible, so certainly not necessarily correct" is confusing. Simply write "(4) is impossible."
- Extra 2 (max of ab) uses (a−b)² ≥ 0, which is not taught. Add "or test the answers: 6·6 = 36 is the biggest".
- Q4 stem "(1 < S, W, D)" is compact notation. Write "S, W, D are all greater than 1."
- Extras: solutions are in words ("five,six,seven,eight"), and some commas have no spaces. Use digits.

## 4. Methods and tricks to add

- **Plug-in checklist** slide (see Coverage). This is the most useful single addition.
- **Test the answers from the extreme:** for "cannot be" with a max/min (Q1), test the most extreme choice first (10 or −10). Say this in Q1 method 3.
- **Integer gap chain** on the memory card: n numbers strictly increasing → last ≥ first + (n − 1). Q1, q-584 and extra 1 all use it.
- **Counting formula** slide (b − a + 1) with a 1–10 example. It fixes q-586 and q-588.
- **Scaling rule** for the strong student: factor^(power ratio).

## 5. Practice

- Quantity: 10 exam-style + 7 extras. OK for a "small part of the exam" topic.
- Order: move the easy extras before q-581.
- Spread: good (easy extras → q-581/q-582 medium → q-583/q-589/q-590 hard). But 3 questions (q-583, q-586, q-588) depend on untaught methods.
- Missing from practice: the scaling type with a new pair of powers (only q-589, which is harder); a "which is largest for 0 < x < 1" question; a formula-structure question like Q4.
- Repetition: extras 3 and 6 are the same idea (squares). Replace one with a sign/size question.

## 6. Verdict

- **Weak:** partly. Can do integer max/min by plugging in. Lost on Q3 (geometry), pigeonhole and counting questions.
- **Medium:** partly. Knows must/can/cannot, but has no clear plug-in checklist, so is unreliable on "which is necessarily true".
- **Strong:** yes. Would like the scaling rule and 1–2 harder practice items.

**Top 3 changes**
1. Add a "which numbers to plug in" slide (0, 1, −1, a fraction, a big number; 0 < x < 1 facts) and one medium guided must/can/cannot question.
2. Q3: lead with the algebra (c² > b²), use 6-8-10, and fix the triangle-inequality sentence. Or move Q3 after T31.
3. Teach counting integers in a range and pigeonhole (or drop q-583). Fix the must/can/cannot wording in q-581/q-585. Move the must/can/cannot card earlier, since T19 already needs it.
