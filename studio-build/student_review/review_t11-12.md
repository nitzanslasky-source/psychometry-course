## Topic 11: Laws of Exponents & Roots — Advanced

**Depends on:** exponent laws (T8), roots (T9), fractional/negative exponents and root techniques (T10), multiplication formulas (x+y)² and a²−b² (T5), zero-product rule and systems of two equations (T6/T7), logic "or" / "necessarily true" (taught in T12 slide 3 and probably T20).
**Needed by:** T12 (x² inequalities, odd powers of negatives), T14/T16 (prime factorization of powers), T18 and T20 (letter expressions), T31/T33 (roots in geometry answers).

### Most important points
1. **Q4 video, slide 3 states a false rule.** "For two different numbers bigger than one, [aᵇ = bᵃ] happens only with two and four." This is true only for **integers**. For real numbers there are infinitely many pairs, e.g. 9/4 and 27/8. Say: "For two different positive **integers**, only 2 and 4." (q-306 already says "integers" — good.)
2. **Section B has no intro lesson.** The topic's only lesson (1.7 min) says "No new rules here". But the solution videos teach new tools: when a power equals 1 (Q3), the 2-and-4 pair (Q4), root of a root = multiply the indices (Q10), a−b = (√a−√b)(√a+√b) (Q11), "never divide by √x" (Q12), raise to the reciprocal power (Q14). A weak student who tries Q3, Q4, Q10, Q11 first (as told) meets them cold. Add a short lesson or board list before Q7, and one line for each tool in Section A.
3. **Two classic exam types are missing** (also missing in T10):
   - Comparing powers with different bases: 2³⁰ vs 3²⁰ → (2³)¹⁰ vs (3²)¹⁰ → 8¹⁰ vs 9¹⁰. Only extra-6 (2¹⁶ vs 4⁷) touches this, and it is trivial.
   - Size order for 0 < x < 1 and for x < 0: x³ < x² < x < √x; sign of (−a)ⁿ by parity. This is the most common NITE "which is largest?" trap.

### 1. Coverage — missing or thin
- Comparing powers (different base / make exponents equal) — see above.
- Numbers between 0 and 1, and negatives — see above.
- Exponential equations that need a common base: 4ˣ = 8ˣ⁻¹, 9ˣ = 27, (1/2)ˣ = 16. Only q-316 and extra-3 (same base) exist.
- Rationalizing with the conjugate: 1/(√3 − √2) = √3 + √2. Q11 uses the formula but never on a denominator.
- (√a + √b)² = a + b + 2√(ab): used in q-310 only.
- Comparing roots of different orders (√2 vs ∛3 → raise both to the 6th power).
- Decimals and powers of 10: (0.2)³, √0.0009, 10⁻³. Missing.
- Well covered: sums of equal powers (Q6, q-311, q-320, q-321), prime-base cancelling (Q1, q-317), x^a = x^b conditions (Q3, q-318).

### 2. Teaching quality per level
- **Weak:**
  - Q3 is very hard: it needs "when is a power 1" AND logic of "or" statements. The "or" logic is taught only in T12. Move Q3 later (end of Section B) or to T20.
  - Q12 video: it opens the brackets, then asks "when does a number equal three times its root?" and guesses 0 and 9. The zero-product route comes only at the end as "Faster". Lead with it: "Product = 0 → each factor = 0."
  - Q14 Method 3: "so the right answer is the reciprocal of sixteen" is a jump. Add: "(1/16)^(−1/2) = 16^(1/2) = 4 ✓".
  - The ":" used for division in solutions (10125:3375, 3x · (1:3)x) looks like a ratio. Use ÷ or a fraction bar.
- **Medium:**
  - Good two-route habit (laws / plug in). Slide 4 "check the choices differ first" is excellent.
  - Q10 plug-in: "The lesson's favourite is four" — never said in this topic. Remove or say "in T10".
  - Q9 Method 1 is long. Faster: rationalize 3/(2√2) = 3√2/4 (as in the text solution) — show this as the main route.
- **Strong:**
  - Good material: Q4 pattern, Q8 estimation, Q13 estimate backup.
  - Missing the hard traps above. Would be bored by extras 1–5.

## Topic 12: Inequalities

**Depends on:** linear equations and moving terms (T6/T7), opening brackets and common factor (T4/T5), substitution in a system (T7), odd/even powers of negatives (T8), squares and square roots (T9), fractions (T2/T3).
**Needed by:** T13 absolute value (|x| < a), T17 number line, T20 algebraic understanding ("necessarily true"), T21 trial and limits, T11 Q3 ("or" logic), T38 geometric reasoning (triangle inequality).

### Most important points
1. **Adding (and not subtracting) inequalities is never taught.** NITE often asks: a > b and c > d → a + c > b + d is true; a − c > b − d is NOT. Also: multiply two inequalities only when all parts are positive. q-350's solution even starts "Add the two inequalities: (a − b) + (something)…" and gives up. Add one slide + 2 questions.
2. **Range of an expression from ranges is only half taught.** Q15 does xy. Missing: x − y (max = max x − min y — the classic trap), x/y, x². Add these to the Q15 slide or as practice.
3. **Reciprocals and 0 < x < 1 are tested but not taught.** Extras 3, 5, 7 need "x² < x for 0 < x < 1" and "a < b, same sign → 1/a > 1/b". No lesson slide covers them. Add a slide "squares and reciprocals of inequalities".

### 1. Coverage — missing or thin
- Adding / subtracting / multiplying inequalities (see above).
- Min/max of x − y, x/y, x² from ranges (see above). Also x² from −3 < x < 2 gives 0 ≤ x² < 9 (not 4 < x² < 9) — a top trap.
- Sign of a product/quotient in general: Q11 and q-354 teach "fraction < 0 → opposite signs", but q-352 (a product 3x(1−3x) > 0) is used before it is taught. Add one line: "Product and quotient follow the same sign rule." A small sign table on the number line would help.
- "Necessarily / could be / cannot be true": the three wordings appear (Q16, q-343, q-357) but are never compared. One slide: "necessarily → find one counterexample to kill; could be → find one example to keep; cannot → find a contradiction."
- Integer counting with ≤ vs < (extra-2, q-344): fine.
- Good: chain with shared side, x² between/outside roots, substitution, test the choices, "x disappears".

### 2. Teaching quality per level
- **Weak:**
  - Slide 4: the "move the terms across" demo on −12 < −4 is confusing. It ends with "1 < 3 … same answer — three greater than one", which students may not see as the same. Better demo: −2x < 6. "Move −2x right, 6 left: −6 < 2x → −3 < x." That is the real use.
  - The tip "don't multiply by a minus" is good, but q-345, q-351 and extra-1 must flip. Add one worked flip (−2x² ≤ −32) so the weak student sees it done once.
  - "Cross-multiply" (slide 6, Q7) is used for multiplying both sides by a positive number. This builds a dangerous habit with unknown denominators. Say "multiply both sides by 6 (positive)".
  - x² > a (outside the roots) is on the board but never worked. Only q-345 tests it.
  - Q13 (four-letter chain) is hard. It helps to draw the order on a number line.
- **Medium:**
  - Videos are clear and short. The plug-in routes (Q1 x = 0 check, Q11) are excellent.
  - Q9: add "the consecutive-fraction pattern x/(x+1) grows with x" — it explains Method 2.
  - Q5 video end: "you could even ignore the ninety — x⁴ < x⁵" is unclear. Either explain (x⁴ < x⁵ → x > 1) or delete.
- **Strong:**
  - Section 1 (Q1–Q4) and extras are easy for them.
  - Good hard items: Q10, Q13, Q15, q-356, q-357. Missing: adding inequalities, x − y range, x² range with a negative lower end.

### 4. Methods and tricks to add
- **New slide "Combining inequalities"** (after "Chain them"): add same direction ✓; never subtract; multiply only if all positive. Example: 1 < a < 3, 2 < b < 5 → 3 < a + b < 8, but a − b: −4 < a − b < 1 (max a − min b).
- **Q15 slide:** add "For x − y: biggest = biggest x − smallest y." And "x² with −3 < x < 2: 0 is inside → x² starts at 0."
- **New slide "0 < x < 1":** x² < x < √x, 1/x > 1. Test with x = 1/4. Links T11 and T17.
- **Checklist for "necessarily true":** try 0, 1, −1, a fraction (½), a big number. Q16 says "always try negatives" — make it a board line.
- **Sign table:** for q-352, q-354, Q11: mark the zeros on the number line, test one number in each part. Faster and safer than two cases.

- **Medium:** Yes for most exam items; will fall on "add/subtract inequalities" and x − y range traps.
- **Strong:** Nearly exam-ready; needs the combining-inequalities and range traps.
