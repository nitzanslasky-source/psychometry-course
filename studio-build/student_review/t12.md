### Q 1 (q-322): Given: \(3 + x < 15 + 3\,x\). For which values of x does the inequality hold?
  (1) \(12 < x\)
  (2) \(6 < x\)
  (3) \(-6 < x\)
  (4) \(3 < x\)
  correct: 2
  solution: Move the x terms to one side and the numbers to the other. Subtract x from both sides: 3 < 15 + 2x . Subtract 15 from both sides: −12 < 2x . Divide by 2 (positive, so no flip): −6 < x .

### Q 2 (q-323): Given: \(3\,\left(4 - 3\,x\right) - 7 < 8 - 9\,x\). For which values of x does the inequality hold?
  (1) \(0\)
  (2) \(12\)
  (3) \(1\)
  (4) Any value
  correct: 3
  solution: Open the parentheses: 12 − 9x − 7 < 8 − 9x , that is 5 − 9x < 8 − 9x . Add 9x to both sides and the x's vanish completely: 5 < 8 . This is a true statement that doesn't depend on x at all, so the inequality holds for every value of x.

### Q 3 (q-324): Given: \(2\,x - 5 < x + 3 < 3\,x - 9\). What is the precise domain in which x can be found?
  (1) \(4 < x < 6\)
  (2) \(7 < x\)
  (3) \(x < 9\)
  (4) \(6 < x < 8\)
  correct: 3
  solution: Split the chain into two inequalities. Left half: 2x − 5 < x + 3 → x < 8 . Right half: x + 3 < 3x − 9 → 12 < 2x → 6 < x . Both must hold, so the intersection is 6 < x < 8 .

### Q 4 (q-325): Given: \(3\,x + 30 < 12 + 6\,x < 30\). For which values of x does the inequality hold?
  (1) \(6 < x\)
  (2) \(x < 3\)
  (3) No value of x (empty set)
  (4) \(0 < x\)
  correct: 2
  solution: Split. Left half: 3x + 30 < 12 + 6x → 18 < 3x → x > 6 . Right half: 12 + 6x < 30 → 6x < 18 → x < 3 . A number cannot be both greater than 6 and smaller than 3, so no x satisfies the chain — the solution set is empty.

### Q 7 (q-328): Given: \(\frac{5\,{x}^{2} - 2}{3} < \frac{2\,{x}^{2} + 20}{2}\). Which of the following is correct regarding x?
  (1) \(16 < x\)
  (2) \(x < -16\)
  (3) \(4 < x\)
  (4) \(-4 < x < 4\)
  correct: 3
  solution: Multiply both sides by 6 (positive — no flip): 2(5x² − 2) < 3(2x² + 20) , that is 10x² − 4 < 6x² + 60 . Subtract 6x² and add 4: 4x² < 64 , so x² < 16 . A square smaller than 16 means the number itself lies strictly between −4 and 4: −4 < x < 4 .

### Q 8 (q-329): Given: \(a + b = c\) and \(a < c < b\). Which of the following necessarily follows?
  (1) \(a \cdot  b < 0\)
  (2) \(a \cdot  b = 0\)
  (3) \(0 < c\)
  (4) \(c < 0\)
  correct: 0
  solution: Substitute c = a + b into the chain. From a < c : a < a + b , so 0 < b — b is positive. From c < b : a + b < b , so a < 0 — a is negative. A negative times a positive is negative, so a·b < 0 must hold. The sign of c itself is not determined (it depends on which of |a| , b is larger).
