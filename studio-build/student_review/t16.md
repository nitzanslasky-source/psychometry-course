### Q 1 (q-457): Given: \(y \ne  0\) and \(\frac{{x}^{6} \cdot  {y}^{5}}{\left|y\right|} < 0\). Which of the following is necessarily true?
  (1) \(x < 0\) and \(y < 0\)
  (2) \(0 < x\) and \(0 < y\)
  (3) \(y < 0\)
  (4) \(0 < y\)
  correct: 2
  solution: x⁶ is an even power, so x⁶ ≥ 0 always. If x were 0 the whole expression would equal 0, not a negative number, so x ≠ 0 and so x⁶ > 0 . Likewise |y| > 0 since y ≠ 0 . So the only factor that can make the expression negative is y⁵ — an odd power, which has the same sign as y. For the quotient to be negative we need y⁵ < 0 , which forces y < 0 . Nothing at all is forced about the sign of x (it can be positive or negative), so choices (1) and (2) claim too much, and (4) contradicts what we found.

### Q 2 (q-458): Given: a, b and c are consecutive even numbers, such that \(0 < a < b < c\). \(\frac{{c}^{2} - {a}^{2}}{b} = ?\)
  (1) \(8\)
  (2) \(6\)
  (3) \(4\)
  (4) \(2\)
  correct: 0
  solution: Consecutive even numbers jump by 2, so b = a + 2 and c = a + 4 . Factor the numerator as a difference of squares: c² − a² = (c − a)(c + a) = 4·(2a + 4) = 8(a + 2) = 8b . Dividing by b gives 8, no matter which even numbers we started from. Check with 2, 4, 6: (36 − 4):4 = 32:4 = 8 ✓.

### Q 3 (q-459): Given: a, b, c and d are integers and consecutive, such that \(a < b < c < d\). \(\frac{d - a}{c - b} - \frac{a - c}{d - c} = ?\)
  (1) \(5\)
  (2) \(4\)
  (3) \(3\)
  (4) \(2\)
  correct: 0
  solution: Write the consecutive numbers as b = a+1 , c = a+2 , d = a+3 . Then every difference is a fixed number: d − a = 3 , c − b = 1 , a − c = −2 , d − c = 1 . The expression becomes 3:1 − (−2):1 = 3 + 2 = 5 . Watch the signs: a − c is negative, and subtracting a negative adds.

### Q 4 (q-460): Let x and y be positive integers. Given: ( x+y ) is odd. Which of the following statements guarantees that the expression x^y + y^x + 7 + 6x will necessarily be odd?
  (1) \(x = y\)
  (2) y is \(\text{even}\) and x is \(\text{odd}\)
  (3) x is \(\text{even}\) and y is \(\text{odd}\)
  (4) the expression can never be \(\text{odd}\)
  correct: 3
  solution: Since x + y is odd, exactly one of x, y is even and the other is odd. Case 1 — x even, y odd: x^y = even^odd = even ; y^x = odd^even = odd ; 7 is odd; 6x is even. Even + odd + odd + even = even . Case 2 — x odd, y even: x^y = odd^even = odd ; y^x = even^odd = even ; 7 odd; 6x even. Odd + even + odd + even = even . Both possible cases give an even result, so the expression can never be odd — no extra condition can rescue it. (Choice (1) is impossible anyway: x = y would make x + y even.)

### Q 5 (q-461): Let x be a nonzero integer. Given: x is even and y is odd. The expression 4y:x³ will always be — Choose the most precise classification.
  (1) \(\text{even}\) or a \(\text{fraction}\)
  (2) \(\text{odd}\) or a \(\text{fraction}\)
  (3) always a \(\text{fraction}\)
  (4) \(\text{odd}\), \(\text{even}\), or a \(\text{fraction}\)
  correct: 2
  solution: Write x = 2k since x is even. Then x³ = 8k³ , so 4y:x³ = 4y:(8k³) = y:(2k³) . The numerator y is odd; the denominator 2k³ is even. An odd number divided by an even number can never reduce to an integer (the denominator carries a factor of 2 that the odd numerator can never supply), so the result is always a non-integer fraction. Check: x = 2 , y = 3 gives 12:8 = 1.5 ✓.

### Q None (q-473): x and y are integers. Given: \(x - y = 6\). Which of the following expressions is not necessarily even?

### Q None (q-474): In class A, every child has 4 pencils, and in class D every child has 5 pencils. The number of children in class D is odd. The total number of pencils of all the children in classes A and D together is necessarily a number that is —
  (1) \(\text{odd}\)
  (2) \(\text{even}\)
  (3) divisible by \(4\)
  (4) divisible by \(5\)
  correct: 0
  solution: Total = 4·(children in A) + 5 ·(children in D). The first term, 4 times anything, is always even. The second term is 5 (odd) times an odd number of children — odd × odd = odd . Even + odd = odd , so the total is necessarily odd. (Being odd, it certainly is not always even or divisible by 4; and e.g. 1 child in A, 1 child in D gives 9 pencils, not divisible by 5.)

For the product j·(4j+1) to equal an odd number, every factor must be odd — so j itself must be odd. If j were even, the product would be even, contradicting that it equals the odd number 2n+1 . (Divisibility by 3 is unconstrained: j = 1 works with n = 2 , and j = 3 works with n = 19 .)

### Q None (q-487): a and b are integers and consecutive. Given: \(x = {a}^{2} - {b}^{2} + 3\,a - 3\,b\). Which of the following statements is necessarily true?
  (1) x is \(\text{even}\)
  (2) x is \(\text{odd}\)
  (3) x is \(\text{negative}\)
  (4) x is \(\text{positive}\)
  correct: 0
  solution: Factor: x = (a−b)(a+b) + 3(a−b) = (a−b)(a+b+3) . Since a and b are consecutive, a−b = ±1 (odd), and a+b is odd (one even, one odd), so a+b+3 is odd+odd = even . Then x = (±1)·(even) = always even. Its sign is not fixed: a=2 , b=1 gives x = 1·6 = 6 > 0 , while a=1 , b=2 gives x = (−1)·6 = −6 < 0 — so (3) and (4) fail.

### Q None (q-488): m and n are integers. \(\left(m + 1\right)\left(4\,n + m\right)\) is necessarily —
  (1) \(\text{positive}\)
  (2) \(\text{even}\)
  (3) different from \(0\)
  (4) divisible by m
  correct: 1
  solution: 4n is always even, so ( 4n+m ) has the same parity as m. Meanwhile ( m+1 ) has the opposite parity to m. So the two factors always have opposite parities — one of them is even — making the product always even. It's not necessarily positive ( m = −2 , n = 0 : (−1)(−2) = 2 , but m = −3 , n = 1 : (−2)(1) = −2 ), it can be 0 (m = −1) , and divisibility by m fails e.g. for m = 3 , n = 1 : 4·7 = 28 is not a multiple of 3.

### Q None (q-489): n is an integer greater than 1. At least half of the numbers between 1 and n (inclusive) are ________.
  (1) \(\text{odd}\)
  (2) \(\text{even}\)
  (3) prime
  (4) not prime
  correct: 0
  solution: Starting the count from 1 (odd), the odd numbers always tie or lead: among 1..n there are ⌈n:2⌉ odd numbers, which is at least n:2 . Examples: n=4 → odds 1,3 (2 of 4, exactly half); n=5 → odds 1,3,5 (3 of 5, more than half); n=9 → 5 odds of 9. Evens are at most half (and fewer when n is odd), and primes fail quickly — among 1..8 only 2,3,5,7 are prime while "not prime" fails for small stretches like 1..3 (only 1 of 3 is non-prime).

### Q None (q-490): a and b are positive integers. Given: \(a \cdot  b = 36\). Which of the following statements is necessarily true?
  (1) \(a \ne  b\)
  (2) \(\left(a + b\right) \le  18\)
  (3) if b is \(\text{odd}\) then a is \(\text{even}\)
  (4) if a is \(\text{even}\) then b is \(\text{odd}\)
  correct: 2
  solution: 36 = 2²·3² . Its odd divisors are 1, 3, 9, which pair with a = 36 , 12, 4 respectively — all even, because an odd b leaves both factors of 2 inside a. So claim (3) always holds. Counterexamples for the rest: a = b = 6 disproves (1); a = 1 , b = 36 gives a+b = 37 > 18 , disproving (2); a = 2 , b = 18 (both even) disproves (4).

### Q None (q-491): Given: \(a < b\) and \(a \cdot  b < c\). Which of the following combinations (of b vs. 0 and c vs. 0) is not possible according to the given data?
  (1) \(0 < b\) and \(0 < c\)
  (2) \(0 < b\) and \(c < 0\)
  (3) \(b < 0\) and \(0 < c\)
  (4) \(b < 0\) and \(c < 0\)
  correct: 3
  solution: If b < 0 , then since a < b , a is also negative (a < b < 0) , so a·b is a product of two negatives — positive. But the given a·b < c would then demand that a positive number be less than a negative c, which is impossible. The other combinations are achievable: (1) a=1 , b=2 , c=5 ; (2) a=−1 , b=2 , c=−1 (ab=−2 < −1) ; (3) a=−3 , b=−2 , c=10 (ab=6 < 10) .

### Q None (q-492): m and n are positive integers. m is even, n is odd. Which of the following expressions is necessarily an integer?
