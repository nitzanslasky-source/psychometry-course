# Topic 7: Equations

## Most important first

- **All answer keys are correct.** There are 3 text errors and 1 math error in the teaching (see Correctness).
- **Slides 5, 6 and 8 give rules but no example on the board.** Slide 6 says "How do you know which one? Practice." A weak student has no method here yet. Give a short checklist and one worked mini-example on each slide.
- **Plugging in is never taught in the lesson.** It first shows up in the Q14 video. After that it is used in Q15–Q18, and its rules are spread across the videos (Q17: "not 1"; Q18: "check the choices are different"). It needs its own slide.
- **The practice sets repeat a lot and are out of order.** q-172 to q-177 are Q1–Q6 again with new numbers. The alg-extra t7-1-x items are copies of t7-5-x. Very easy items (6x+8=68) come *after* exam-hard ones (q-208, q-214).

## 1. Coverage

Well covered: dividing by an unknown, product = 0, ± roots, "necessarily true", building an expression by adding or subtracting, hidden short-multiplication formulas, matching coefficients "for every x", ratio chains, and a² + b² = 0.

Missing or only mentioned in passing:
- **x + 1/x type** (for example, x + 1/x = 3, so x² + 1/x² = ?). This is a classic NITE use of the hidden formula. It is missing everywhere.
- **Multiplying or dividing equations.** Slide 6 says "sometimes dividing", but only Q16 does it (by multiplying). Add one question like xy = 12, yz = 6 → x/z = ?, or x²y = 18, xy = 6 → x = ?
- **Systems with a parameter.** For example: for which k does 2x + ky = 4, x + 3y = 2 have no solution, or infinitely many? T6 covers this for a single equation only.
- **Simple quadratic trinomials** (x² − 5x + 6 = 0, found by factoring or by testing the choices). I found none in the whole course (I searched t1–t38). NITE asks this now and then. Give it one slide here, including the shortcut "test the answer choices".
- **Extraneous solutions after multiplying by a denominator**, for example (x² − 9)/(x − 3) = 0. T6 slide 5 teaches it, but T7 has no practice question on it. Add one.

## 2. Teaching quality per level

**Weak student**
- Slides 5–8: the board has only words. Slide 7 shows the formula but no numbers. Slide 8 shows "2a = a + a" and nothing else. Put one mini-example on each.
- The Q11 video says "First short multiplication formula" and the Q15 video says "the third formula". A weak student does not remember the numbering. Say the name and write it on the board: (a + b)² = a² + 2ab + b².
- Q10 method 2 ("diagonal partners can swap") is new and goes fast. Method 1 (cross-multiply every choice) is enough for a weak student. Tell them so.
- The alg-extra solutions are one line and skip steps. For example, t7-5-5: "Exclude the zero denominator, then multiply by twice the denominator." A weak student cannot follow this. Write out the steps: 2(x − 6) = x + 8 → x = 20.
- Q20: add one line explaining why "cannot be determined" is wrong. Many weak students choose it.

**Medium student**
- Needs one decision rule for "asked for an expression" (slide 6). See section 4.
- Q12 and Q14 give useful clues in the video ("which letter is missing from the answers?"). This belongs in the lesson, not only in the videos.

**Strong student**
- The lesson is short and good. The strong student is bored by the easy alg-extra items and the clone set.
- Wants more hard traps: x + 1/x, systems with a parameter, the "no solution" and "any pair" type (q-215 is a good one, add more).

## 3. Correctness

- **q-214 solution is broken.** "Then 4x + 3y ≤ 4 + 3 = 7  1 , y > 1 must be true." Text is missing. It should say: "≤ 7 < 10, a contradiction. So x > 1 or y > 1." The key (choice 1) is correct.
- **Q16 video, Method 3, "Brainwave two" is wrong as stated.** "Each letter is bigger than the next" is false for negative numbers. Example: y = −1, x = 2y = −2, so x < y. The correct reason: x/w is a product of ratios that are all bigger than 1, so x/w > 1. Change the sentence.
- **Division written as ":" in the solutions** (q-184 "22 · 15:11", q-199 "1:(x + y)", q-216). In English this reads as a ratio. Use fractions or "÷".
- **"Given: 0 < m, n"** (q-203) and **"0 < x, a"** (q-204) are ambiguous. Write "m > 0 and n > 0".
- **q-203, choice 4 "m² − 2"** gives m in terms of m. It is a weak distractor. Replace it, for example with "−n".
- **Check the rendering:** the pre-loaded question text in the videos shows raw LaTeX ("2\,x", "{x}^{7}"). Q4 shows "a − 5\,b/4" with the fraction lost, which reads as a − (5b/4). Make sure the real slide shows the fraction.
- **"Q None"** appears on every practice item. Check that the real numbering is shown.

## 4. Methods and tricks to add

- **New slide after slide 6: "Which operation?"** Put a checklist on the board:
  1. Same coefficients in mirror order (3x + 7y and 7x + 3y) → add, and maybe also subtract.
  2. A letter that is missing from the answers → eliminate that letter first.
  3. Ratios or products → multiply or divide the equations.
  4. Asked for k·(target) → multiply one equation so the unwanted letter cancels (as in Q14).
- **New slide: "Plug in numbers."** Say when to use it: letters in the answers. Give the rules: avoid 0 and 1, and values that make choices equal; check all four choices; the numbers must satisfy the given equation (Q18: choose y first, then find x). Also "work back from the choices" (Q15 method 3).
- **Slide 7:** add the pair (x + y)² and (x − y)², and write the "know 2, get the 3rd" triangle: x ± y, x² + y², xy. Add x + 1/x as a second example.
- **Slide 2:** add "or check x = 0 separately". This is a faster habit for the exam.
- **Q8:** the estimation method is excellent. Keep it and use it again in one practice question.

## 5. Practice

- Count: 20 guided, 20 practice, 6 source variants and 14 alg-extra. That is enough, but about 20 of these are clones.
- Remove the t7-1-x set (copies of t7-5-x). Keep q-172 to q-177 only as a "retry" set, or remove them.
- Order the practice easy → hard. The alg-extra items (6x + 8 = 68) should come first, then q-198 onward.
- Good hard items: q-208, q-213, q-214, q-215, q-216, q-217. Keep them.
- Missing practice for: plugging in on purpose, dividing equations, x + 1/x, parameter systems, quadratic trinomials.

## 6. Verdict

- **Weak:** Can solve the Q1–Q5 types. Gets lost on "build the expression" and on the terse practice solutions. Not ready yet.
- **Medium:** Mostly ready. Needs the "which operation" checklist to be reliable.
- **Strong:** Ready. Wants harder traps and less repetition.

**Top 3 changes**
1. Add the "Which operation?" slide and a "Plug in" slide, and put a mini-example on the board for slides 5–8.
2. Fix the q-214 solution, the Q16 "Brainwave two" sentence, the ":" division notation and the "0 < m, n" wording.
3. Remove the clone sets and reorder the practice easy → hard. Add x + 1/x, dividing equations, parameter systems and quadratic trinomials.

# Topic 8: Exponent Laws — Fundamentals

## Most important first

- **All answer keys are correct.**
- **Some ideas are used before they are taught.** Slide 3 uses "subtract exponents" (taught on slide 7). Slide 4 uses "negative exponent" (taught on slide 5). q-227 and alg-extra-2 use fractional exponents (7³)^(2/3) and 27^(2/3), which are taught in T9. alg-extra-7 (√50 + √8) is a roots question and belongs in T9.
- **Slide 12 overclaims.** It says 2 and 4 is "the one special case… Any other pair of different numbers? One side is always bigger." This is true only for positive whole numbers.
- **Too few exam-level questions.** The 10 core questions are one-step recall. Only q-226, q-231 and q-232 are exam-style.

## 1. Coverage

Well covered: definitions, exponents 0 and 1, bases 0 and 1, negative exponents, the 3 main laws, same exponent, negative bases and brackets, aᵇ = 1, and splitting 2ⁿ⁺³.

Missing or only in passing:
- **"Copies" rule:** 2ⁿ + 2ⁿ = 2ⁿ⁺¹ and 3·3ⁿ = 3ⁿ⁺¹. This is a very common NITE trap. It is only taught in T11. Add one line to slide 13, where it fits naturally.
- **Powers of fractions and decimals:** 0.1³, 0.2², and the fact that squaring a number between 0 and 1 makes it smaller. This is very common on the exam. Add one slide or one practice question here.
- **Comparing powers:** use the same base (2¹⁰ vs 4⁴) or the same exponent (2³⁰ vs 3²⁰ → 8¹⁰ vs 9¹⁰). Only alg-extra-6 touches this.
- **Counting zeros:** 2⁵ · 5³ = 4 · 10³. q-228 is the easy version. Add the uneven version.
- **Sign with letters:** x³ < 0 → x < 0. x² gives no sign information. (−x)² vs −x².
- **Rewriting to the smallest prime base:** it appears only as a memory-card tip. T10 teaches it. Tell students here that it is coming.

## 2. Teaching quality per level

**Weak student**
- Slide 3: the "5³/5³" proof uses a law they have not met yet. Either move this proof to after slide 7, or show it by cancelling: (5·5·5)/(5·5·5) = 1.
- Slide 4: "A negative exponent means dividing by zero" comes before slide 5 explains negative exponents. Put slide 5 first, or skip the reason on slide 4.
- The core questions have no solution videos. That is fine for q-218 to q-225. It is not enough for q-226 (a negative minus a negative) or q-231. Add short videos for these.
- Slides 6 and 8 (the "add vs multiply" confusion) are good. Keep them.

**Medium student**
- Needs a drill on "which law?" with mixed structures. Now each law has its own question. Add 3–4 mixed ones, for example (2³)² · 2⁻⁴ / 2².
- The memory card is good. Add powers of 2 up to 2¹⁰ = 1024, powers of 10, and (−1)ⁿ.

**Strong student**
- Bored by q-218 to q-225. Let them skip to a "hard set".
- Wants the traps listed in Coverage.

## 3. Correctness

- **Slide 12 and memory-card tip 1** ("the one time swapping base and exponent gives the same number"). This is false in general. Example: (−2)⁻⁴ = (−4)⁻² = 1/16, and many non-integer pairs also work. Say: "Among positive whole numbers, only 2 and 4." q-232 itself is correct, because it says positive integers.
- **q-232 wording** ("Let a and b be positive integers… What is a + b?") does not use NITE style. Write: "Given: a and b are positive integers, a < b, aᵇ = bᵃ. a + b = ?"
- **alg-extra-6:** the choice "It cannot be determined" makes no sense for two fixed numbers. Replace it with a real distractor.
- **Slide 4** says "Zero to the zero? Not defined in this course" (fine). **Slide 11** says "b must be even": make it "b even whole number".

## 4. Methods and tricks to add

- **Slide 13 (splitting):** add "copies": 2ⁿ + 2ⁿ = 2·2ⁿ = 2ⁿ⁺¹, and 4ⁿ + 4ⁿ + 4ⁿ + 4ⁿ = 4ⁿ⁺¹.
- **New short slide, "Between 0 and 1":** 0.5² = 0.25, which is smaller. (1/2)ⁿ gets smaller as n grows. Decimal powers: count the decimal places (0.2³ = 0.008).
- **New short slide, "Compare powers":** make the bases the same, or make the exponents the same. Example: 2³⁰ vs 3²⁰.
- **Plug-in check for letter questions** (q-224): test x = 1 → 5³ = 125, and only 25·5 = 125. This builds the habit early.
- **Order:** slides 2 → 5 (negative exponent) → 3–4 (0, 1 cases) → 6–9 → 10–13.

## 5. Practice

- 22 questions in total. Only 3–4 are exam-level. Add 8–10 exam-style questions: copies, comparing, 0 < x < 1, zeros counting, sign with letters, and aᵇ = 1 with letters.
- Move q-227, alg-extra-2 and alg-extra-7 to T9 or T10, or teach a^(1/n) first.
- The easy → hard spread is fine but ends too early. Nothing is exam-hard except q-232.

## 6. Verdict

- **Weak:** Will learn the laws. May be confused by slides 3–4 and by q-227. Needs the order fix.
- **Medium:** Can solve the basic questions. Not yet the exam traps (copies, comparing, fractions).
- **Strong:** Learns it fast. Leaves without the hard traps, which only come in T10–T11.

**Top 3 changes**
1. Fix the order (slides 3–4 before 5 and 7). Move the fractional-exponent and roots questions to T9/T10. Correct the slide 12 and memory-card overclaim.
2. Add the exam traps: copies (2ⁿ + 2ⁿ), numbers between 0 and 1 and decimals, comparing powers, sign with letters.
3. Add 8–10 exam-level practice questions, with short videos for the harder ones. Extend the memory card (2¹⁰, 10ⁿ, (−1)ⁿ).
