### Q None (q-233): \(\sqrt[3]{8} - \sqrt[3]{0} - \sqrt[3]{-1} = ?\)
  (1) \(-3\)
  (2) \(1\)
  (3) \(3\)
  (4) \(2\)
  correct: 2
  solution: Evaluate each cube root: ∛8 = 2 , ∛0 = 0 , and ∛(−1) = −1 (odd roots of negatives exist). Then 2 − 0 − (−1) = 2 + 1 = 3 .

### Q None (q-234): \(\sqrt[6]{-64} = ?\)
  (1) No real value
  (2) \(2\)
  (3) \(-2\)
  (4) \(-8\)
  correct: 0
  solution: An even-index root of a negative number has no real value: any real number raised to the sixth power is non-negative , so nothing to the sixth power equals −64 .

### Q None (q-235): \(\sqrt[3]{{5}^{6}} = ?\)
  (1) \(25\)
  (2) \(125\)
  (3) \(5\)
  (4) \(\sqrt{5}\)
  correct: 0
  solution: A root is a fractional exponent: ∛(5⁶) = 5^(6:3) = 5² = 25 .

### Q None (q-236): \({81}^{\frac{1}{4}} = ?\)
  (1) \(9\)
  (2) \(27\)
  (3) \(3\)
  (4) \(1\)
  correct: 2
  solution: A 1:4 exponent is a fourth root: 81^(1:4) = ⁴√81 = 3 , since 3⁴ = 81 .

### Q None (q-237): \(\sqrt{27} \cdot  \sqrt{3} = ?\)
  (1) \(6\)
  (2) \(3\)
  (3) \(81\)
  (4) \(9\)
  correct: 3
  solution: Merge the product under one root: √27 · √3 = √(27·3) = √81 = 9 .

### Q None (q-238): \(\sqrt{31} \cdot  \sqrt{31} = ?\)
  (1) \(62\)
  (2) \(31\)
  (3) \(0\)
  (4) \(1\)
  correct: 1
  solution: By definition, a square root times itself returns the number under the root: √31 · √31 = 31 .

### Q None (q-239): \(\sqrt[3]{9} \cdot  \sqrt[3]{9} \cdot  \sqrt[3]{9} = ?\)
  (1) \(9\)
  (2) \(27\)
  (3) \(3\)
  (4) \(1\)
  correct: 0
  solution: Three copies of a cube root multiply back to the number under it: (∛9)³ = 9 .

### Q None (q-240): \(\frac{\sqrt{50}}{\sqrt{2}} = ?\)
  (1) \(5\)
  (2) \(10\)
  (3) \(25\)
  (4) \(2\)
  correct: 0
  solution: Combine into a single root: √50:√2 = √(50:2) = √25 = 5 .

### Q None (q-241): \(\frac{\sqrt{3}}{\sqrt{48}} = ?\)
  (1) \(\frac{1}{8}\)
  (2) \(\frac{1}{6}\)
  (3) \(\frac{1}{4}\)
  (4) \(\frac{1}{2}\)
  correct: 2
  solution: Merge under one root: √3:√48 = √(3:48) = √(1:16) = 1:4 .

### Q None (q-242): Evaluate \(\sqrt[2.5]{\sqrt{243}}\). Here the fractional root index \(2.5\) means raising to the power \(\frac{1}{2.5}\), i.e. \(\sqrt[2.5]{\sqrt{243}} = \left(\sqrt{243}\right)^{\frac{1}{2.5}}\) (the radicand is positive).
  (1) \(9\)
  (2) \(27\)
  (3) \(3\)
  (4) \(1\)
  correct: 2
  solution: Use fractional exponents: (243^(1:2))^(1:2.5) = 243^(1:5) = 3, because 243 = 3^5. This is an extension of the integer-index root rules; the positive input makes the real-valued interpretation unambiguous.

### Q None (q-243): \(3 \cdot  \sqrt{7} = ?\)
  (1) \(\sqrt{63}\)
  (2) \(\sqrt{147}\)
  (3) \(\sqrt{21}\)
  (4) \(\sqrt{10}\)
  correct: 0
  solution: Bring the 3 inside the root by squaring it: 3·√7 = √9 · √7 = √(9·7) = √63 .

### Q None (q-244): \(3 \cdot  \sqrt[3]{2} = ?\)
  (1) \(\sqrt[3]{54}\)
  (2) \(\sqrt[3]{5}\)
  (3) \(\sqrt[3]{24}\)
  (4) \(\sqrt[3]{6}\)
  correct: 0
  solution: To enter a cube root, the 3 must be cubed: 3·∛2 = ∛27 · ∛2 = ∛(27·2) = ∛54 .

### Q None (q-245): Which of the following is the smallest?
  (1) \(\pi \)
  (2) \(3\)
  (3) \(\sqrt[3]{30}\)
  (4) \(\sqrt{7}\)
  correct: 3
  solution: Estimate each: √7 ≈ 2.65 (between √4 = 2 and √9 = 3 , closer to 3); ∛30 is slightly above ∛27 = 3 , so ≈ 3.1; π ≈ 3.14 . Ordering: √7 < 3 < ∛30 < π , so √7 is smallest.

### Q None (q-246): Which of the following is closest to \(\sqrt{3}\)?
  (1) \(1.6\)
  (2) \(1.7\)
  (3) \(1.8\)
  (4) \(1.9\)
  correct: 1
  solution: √3 ≈ 1.732 . The distances are: |1.732 − 1.7| ≈ 0.032 versus |1.732 − 1.8| ≈ 0.068 , so 1.7 is closest.

### Q None (q-247): Given: \(x = \sqrt{5\,x}\). The number of solutions of the equation is —
  (1) \(4\)
  (2) \(0\)
  (3) \(2\)
  (4) \(1\)
  correct: 2
  solution: Square both sides (valid for x ≥ 0 , which the equation requires): x² = 5x , so x² − 5x = 0 , giving x(x − 5) = 0 . Thus x = 0 or x = 5 . Both satisfy the original equation ( 0 = √0 and 5 = √25 ), so there are 2 solutions.
