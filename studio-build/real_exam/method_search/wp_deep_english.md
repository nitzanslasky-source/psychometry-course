# Word problems (topics 21-29) in the official ENGLISH NITE exams, Summer 2020/22/23/24/25/26: deep method search
Read-only. Every answer below was checked against the official key (all match). Id = year-section-question.
Format: id · type · fastest route · taught? (t = course topic dump)
Method tags: [FACTOR] = compare two situations by multiplying the change factors (generalized V); [PARTS] = ratio parts + a given sum/difference; [FREE1] = first pick is free; [PAIRS] = unlabeled pairs/groups; [AGE] = everyone changes by the same step; [CANCEL] = question-defined formula, shared parts cancel.
